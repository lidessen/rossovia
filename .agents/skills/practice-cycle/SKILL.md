# Practice Cycle（实践回返）

给定一次真实实践的结果，判断下一项最小实践如何修订或收敛当前理解——反馈改变后续判断才构成学习（theory/harness.md：iterative-improvement；P03 实践-认识往复，P15 检验手段，P16 检验时点）。

## 何时使用

- 一次实践/实验/试用结束后，需要判断下一步或收敛理解时。
- 偏差纠偏也是本 skill 的实例（AGENTS.md 第 5 章：发现偏差 → 限制影响 → 区分 → 最小修正 → 隔离验证 → 沉淀或回退）。

## 核心方法

1. **定位实际对象**：把观察（现在可复现地发生了什么）、推断、候选、未知分开，不混称。
2. **命名活矛盾**：找出阻止下一行动的未知/矛盾（能行动就不叫活矛盾）。
3. **选一个最小可逆实践**：能改变后续判断的最小动作；低风险、可逆。
4. **由真实 owner 执行观察**：不替 owner 执行；观察结果要有来源。
5. **反观察回看**：这次实践是否改变了后续判断？不能改变后续决策的动作不构成学习，不外化。
6. **处置**：`settle`（收敛，进入结算）/ `continue`（同一方向下一实践）/ `route`（交给其他 owner）/ `uncertain`（保留未知，闭环暂停）。

## 边界

- 不把重复动作冒充学习；不把格式通过、文件存在、Agent 自称完成当接受。
- Principal 改变目标时，先废止旧判断再继续（不沿用失效的 acceptance）。
- 只外化会改变后续决策的学习；一次实践不足以沉淀 skill（那是 skill-formation）。

## 返回

处置结果 + 一句话理由 + 下一实践建议（或"无下一实践，闭环"）。
