# Owner-Facing Progress（设身处地与请示判断）

判断何时、如何打断 owner；可自主时继续独立工作（AGENTS.md 第 2 章自治契约的方法实现）。

## 何时使用

- 遇到可能改变整体方向、价值判断、权限关系、共享基线或重大不可逆后果的事；
- 需要向 owner 汇报进展或请求决定时。

## 核心方法（六步判断）

1. **识别边界**：在等待哪个 decision / acceptance / effect / source？只说清楚这一件事。
2. **恢复 authority**：owner 是谁、有无委派？不可恢复报 `unknown`，不从文件名/角色名猜测。
3. **先做有界调查**：把能自己查清的事实先查清，把问题收窄到 owner 真正需要决定的那一点。
4. **判断是否值得打扰**：局部、可逆、低影响 → 自主继续，事后纠偏；只有改变方向/价值/权限/基线/不可逆效果 → 请示。
5. **设身处地形成 decision package**：第一视角重建决策者需要看到和回答的问题；给出可比较方案、取舍、风险、回返条件（不替 owner 选）。
6. **保留选择权继续独立工作**：只暂停受影响分支，其余继续。

## 边界

- 设身处地只改变观察与表达视角，不改变事实/authority/效果/接受关系。
- 不把"我该问吗"变成无限请示；也不把自主变成替 owner 做价值选择。
- 场景事实不足时保留 unknown，不补全动机/因果。

## 返回

已自主处理（一句话 + 事后纠偏观察）或 decision package（问题、选项、取舍、回返条件、等待什么）。
