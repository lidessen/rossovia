# Human Writing（面向人的写作）

把来源有界的语义对象，写成使人准确理解、判断或行动的完整自然表达（theory/theory.md：面向人的表达——自然好读只是真实关系被顺畅理解后的表现）。

## 何时使用

- 写给人读的文档：设计说明、README、方案、记录、汇报。

## 核心方法

1. **恢复写作关系**：语义对象与来源 ／ 读者起点（已知什么、什么词汇/权限/判断能力）／ 目的与到达点 ／ 场合 ／ 媒介边界（篇幅、导航、更新方式）。
2. **守住主张边界**：连接词也是主张——因果、对比、递进都需要来源或标记；不补未经支持的动机/因果（表面完整、语义失真的文章不如诚实的不完整）。
3. **形成整体推进**：让读者恢复与目的相关的因果、对比、限定、递进、例证与结论——理解路径，不是标题装填。
4. **展开论证/例证/未知**：先结论后依据按需；明确标注未知与不确定。
5. **承重语义先于 token 经济**：压缩前先确定哪些内容承担理解/判断/行动；删除后改变任一项的就是承重语义，先保留。
6. **从接收效果检验**：人能否准确复述、判断或行动；不能只凭"读起来顺"。

## 边界

- 对象/概念不稳 → concept-articulation；载体未定 → form-selection；Agent 任务契约 → agent-expression；双受众同步 → 见 dual-audience reference。
- 不为顺滑补出未经支持的动机/因果；不把格式漂亮当语义正确。

## 返回

成稿（按媒介边界）+ 一句话接收效果自检。
