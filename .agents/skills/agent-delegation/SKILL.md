# Agent Delegation（Agent 委派）

判断整体工作中的真实有界贡献是否/如何交给另一 Agent；委派是保持整体关系的有界转交，分出去的是有界贡献，不是整体责任（theory/harness.md：agent-delegation）。

## 何时使用

- 多步/多 Agent 协作前；深调查、独立来源面、调用 Main 不具备的能力时。
- 先 `work-estimation` 恢复整体工作图，再判断是否委派。

## 核心方法

1. **恢复整体义务**：Main 持有整体——目标、硬约束、接受关系、non-goals；不因委派转移。
2. **六准入**（都满足才委派）：可指认的局部变换 ／ 可分来源 ／ 接收者可行动 ／ 返回可重连 ／ 收益 > 成本 ／ Main 可恢复约束。
3. **三问题识别贡献边界**：改变整体的什么？下游哪个判断用它的结果？什么证据重连？
4. **拓扑服从真实依赖**：独立 → 并行；顺序依赖 → 顺序；深调查 → 嵌套（child 不获得父的外层 authority，深度是组织选择）。
5. **贡献契约**：对象与目标、来源与允许效果、完成观察、返回关系（证据重连）、边界与 non-goals、未知处理。
6. **producer/reviewer/接受者分离**：执行者不评估自己；评审者没参与候选形成；接受归 owner。
7. **证据重连综合**：child 返回的是带 standing 的局部主张，不是自动事实；Main 综合是恢复关系，不是拼接报告或多数投票。

## 边界

- 多主题、多文件、空闲 Agent 不构成委派理由；短任务、耦合判断、共同前提未确立时保持直接。
- 复制同一宽 prompt 只产生伪共识；协调成本超过原工作时停止扩张。
- 委派不授予被委派者全局 authority；采纳/合并/发布仍属原接受拥有者。

## 返回

委派判断（直接/顺序/并行/嵌套 + 理由）、贡献契约、重连证据清单。
