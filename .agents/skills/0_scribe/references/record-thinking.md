# 记录对话思考

把对话中用户偶发的思考片段追加到 `notes/thinking-log.md`（不存在则创建，保留文件头说明）。遵循 SKILL.md 的核心原则：忠实还原、润色有界、不补全、不添加。

## 条目格式

```markdown
### THINK-YYYY-MM-DD-NNN

来源：<会话主题或上下文，一句话>

原文：

> <忠实还原的思考内容；语义转折明显时按片段分行>
```

- 条目 id `THINK-` 用于回指，同日按序号 001、002……递增。
- 同一次对话中的多条思考各自成条或按语义转折成组，保持出现的先后顺序。
- 只追加，不改写已写下的条目；用户后续修正或撤回时新增一条并注明修正关系，旧条目保持原样。

## 示例

```markdown
### THINK-2026-08-26-001

来源：讨论记录方式时的插话

原文：

> 以后类似的、带观点性质的、想法性的和思辨性的内容，都要先记录下来，不要等它成熟了才记。
```

## 边界

- 不因内容「不成熟」「不确定」而不记录。
- 记录只是保留原始想法，不自动成为计划、任务、承诺、优先级、owner、研究结论或 acceptance。

## 返回

记录完成后简短返回：条目 id、写入位置、一句话摘要；不必复述全文。未写入时返回记录文本与原因。
