# Dual-Audience Expression（双受众表达 reference）

供 `expression`（面向人 / 面向 Agent 两模式）共用的低频参考。当同一语义核需要同时面向人与 Agent 时使用。

## 准入

真实双受众 + 共享承重语义 + 可观察的同步关系（如 AGENTS.md 自身、README + 路由表）。单一受众、无共同语义核、对象不稳 → 不适用。

## 方法

1. 恢复共享语义核：对象/来源/范围/权威/证据（单一语义源——一个语义事实只有一个权威回答）。
2. 按接收关系形成不同视图：人视图（背景/理由/例子/未知）；Agent 视图（对象/来源/允许效果/判断/返回）。
3. 建立权威/派生/追溯：派生视图是 projection，不因便于消费取得独立权威。
4. 来源先变再同步；语义回归按共享语义与接收效果检查，不是文本对齐。

## 边界

- 不预建两套视图；无真实双受众时不套用。
- 派生视图不能取得第二权威；单一语义源只减少漂移，不保证来源正确。
