# Expression（表达：概念 → 载体 → 表达）

同一"表达"主题下的处理链——语义对象进来：先定义概念（是什么）→ 选载体（用什么形式落地）→ 表达（面向谁写/执行）。三个环节可独立触发（概念歧义 / 载体选择 / 写作或任务表达）。

## 何时使用

- **概念环节**：对象/概念/名称/定义有歧义，或要确立正式指称时。
- **载体环节**：语义对象要落地（确定用任务表达/文档/skill/工具/runtime 时）。
- **表达环节**：写给人读的文档（面向人）；写给 Agent 执行的契约/方法（面向 Agent）。
- 不使用：记录/反馈（`feedback-loop`）、编排委派（`work-orchestration`）、机制判断（`mechanism-design-review`）。

## 环节 1 · 概念定义（吸收 concept-articulation）

让现实中的区别成为可共同判断的区别（P14 名不正则言不顺）。

1. 从对象证据与来源状态开始（不接受请求里的名称）；对象不可指认/来源不足 → no-proposal。
2. 恢复最小关系视图：上位/并列/外延/整体部分/关联——最近邻是最可能导致误判的概念。
3. 四探针照验边界：包含（正例入界？）/ 排除（反例出界？）/ 最近邻（与易混淆者可分？）/ 反例（什么不算它？）。
4. 先定义后指称：定义足够区分、不求说尽；「最小」服从「充分」。
5. 临时 handle 守三边界：状态（provisional）/ 作用域 / 结论（不预设类别因果价值）。
6. 行动检验：改名但概念关系不变时，涉及该概念的判断/行动应基本稳定。

返回：定义 + 指称 + 最近邻区分；或 no-proposal + 缺口。

## 环节 2 · 载体选择（吸收 form-selection）

为来源有界的语义对象选最小真实形式——不增加无主权威、重复维护、无用机制。

1. 恢复四项使用关系：受众 / 目的 / 预期行动 / 媒介。
2. 外部关系：不可变契约、权威源、consumer、生命周期、提示外硬属性（强制/权限/唤醒/原子性/恢复）。
3. 比较相邻真实形式（逐一问"能不能由更小的现有形式承担"）；选最小真实形式（权威与维护风险最小，非最短文本）。
4. 载体能力分界（harness.md）：Markdown 表达不了强制执行/唤醒/权限/原子性/恢复/跨 store 交接/持久身份——这些要求出现时重新检验。
5. no-proposal 时给可区分候选的使用探针。

返回：选定形式 + 理由；或 no-proposal + 使用探针。skill 载体候选 → `skill-formation`。

## 环节 3 · 表达

### 面向人（吸收 human-writing）

1. 恢复写作关系：读者起点 / 目的与到达点 / 场合 / 媒介边界。
2. 守住主张边界：连接也是主张——因果/对比/递进需来源或标记；不为顺滑补未经支持的动机/因果。
3. 形成整体推进：理解路径（因果、对比、限定、递进、例证、结论），不是标题装填。
4. 承重语义先于 token 经济：删掉后改变判断/行动的内容先保留。
5. 设计文档结构纪律（019A）：正式 design 保持干净规范主体，历史/审计进过程记录。
6. 从接收效果检验：人能否准确复述、判断或行动。

### 面向 Agent（吸收 agent-expression）

1. 恢复行动关系：对象与期望改变 / 来源与事实状态（指令/现状/候选/未知/参考）/ 接收上下文 / 允许效果与停止边界 / 判断与验收 / 失败与未知 / 返回关系。
2. 区分事实/指令/候选/参考/未知；不把愿望伪装成环境事实。
3. 组织顺序服从行动依赖；承重语义优先于默认简洁。
4. 验收三层分离：产物产生 ≠ 验证观察到 ≠ 有权接受。
5. 接收者方法由 harness 承担：不重复方法性 instruction，harness 不足补 harness（详见 `work-orchestration` 委托 prompt 最小化）。

### 双受众

同一语义核需同时面向人与 Agent 时：见 `references/dual-audience.md`（单一语义源，来源先变再同步，派生视图不取第二权威）。

## 边界

- 概念不稳 → 留在环节 1（不进入载体/表达）；载体未定 → 环节 2；编排/委派判断 → work-orchestration；机制准入 → mechanism-design-review。
- 名称、定义、概念、对象四者不能互相顶替（已有名称不证明对象找对；例子不等于定义）。
- 结构化输出只在需要机械解析时占优；格式符合只证明格式，不证明事实正确或已被接受。
- 提示外硬属性属 runtime，文字不产生权限。
