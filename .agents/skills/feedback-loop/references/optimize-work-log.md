# 优化 Work Log

优化用户手动维护的 `notes/work-log.md`（从 0_scribe 迁移）。遵循本 skill 的核心原则，尤其是「不添加」：不添加用户没有写的结论、不改写决策或结论本身。

## 何时使用

用户要求优化 `notes/work-log.md`，如「润色一下 work log」「整理一下实验记录」。

## 优化范围（只做三件事）

- 润色不通顺、语法与表达问题，使记录可读；
- 轻量规范化：日期规范为 `YYYY-MM-DD`（如「8.26」→ `2026-08-26`），每条补一个从内容提炼的简短标题；
- 保持全部原有内容：正文保持段落、不强行拆分字段、不删承重细节、不添加用户没有写的结论、不改写决策或结论本身。

## 边界

- 优化不改写用户的决策与结论语义；结构调整不改变条目归属与事实。
- 提炼的标题只是便于回读的结构元素，不添加新语义；用户不认可时按其偏好调整。
- 用户明确要求改写某条结论时，按新语义更新并注明修订关系，不静默覆盖旧表述。
- 优化只是整理记录，不使记录自动成为计划、任务、承诺或 acceptance。

## 返回

完成后说明改了什么：哪些是润色、哪些是规范化（日期/标题），让用户能核对。
