## 哲学序列（philosophical sequence）

哲学基础是问题处理领域里一行行的基本观点——怎么认识问题、怎么分析问题、怎么解决问题。每一条管一个环节，只取经典原句。

入选标准：脍炙人口，中文能单独站住；能生（解读、方法、约束可从它长出）；能判（换成别句以后有一类选择会变）；不可约（不是拼接）；一行（无藏起来的步骤）。

| 编号 | 条目 | 环节 |

| P02 | 没有调查，没有发言权 | 认识·证据 |
| P03 | 实践、认识、再实践、再认识 | 认识·深化 |
| P04 | 知之为知之，不知为不知 | 认识·已知边界 |
| P05 | 具体问题具体分析 | 分析·特殊性 |

| P07 | 天下难事，必作于易 | 分析·入手点 |
| P08 | 井蛙不可语海，夏虫不可语冰 | 分析·问题边界 |
| P09 | 抓住主要矛盾 | 解决·主次 |

### 为什么条目值得单独保留

1. **可再生**：条目是基因型——即使 skill 方法及载体全部消失，也能按情景重新生成方法与载体。
2. **抗漂移**：模型更新、系统提示词变化先改变载体适配与激活表现，不改条目层；稳定的放条目层，易变的放方法表达层。
3. **可诊断**：载体或激活表现不好，可沿血统回看是生成时没内化关键关系、载体没表达完整方法，还是环境失真。
4. **可再生地组合**：同一批条目在不同环境冲撞长出不同方法；同一方法可编码为不同载体。

### 生成指引：认识 → 分析 → 解决（三段推导序列）

条目不是大海捞针找出来的，而是按环节生成：**怎么认识问题（是什么）→ 怎么分析问题（什么结构）→ 怎么解决问题（怎么做成）**。段落是先后关系，每段环节有限、闭环：

- **认识**：来源（事实从哪来）→ 证据（凭什么说）→ 如实 → 深化（一次够吗）→ 已知边界（知道多少算知道）；
- **分析**：特殊性（与一般什么关系）→ 简化（怎么删繁就简）→ 入手点（从易处还是难处）→ 问题边界（划到哪）；
- **解决**：主次（先解哪个）→ 时机（何时最便宜）→ 成本（花多少代价）→ 对抗·知 → 对抗·应 → 表达（如何让实践主体行动）→ 检验（是否真正解决）。

环节表是生成层（指引"下一句找什么"），坐标表是校准层（检查"这一句偏没偏属"）。环节之外的需求（注意力、计划、风险）是环节间的组合（三），不进序列；由「一」回答的问题（目标、范围）是问题化本身，也不进序列。

### 序列的性质与候选检验

哲学序列是**方法论的条目集**，不是警句收藏；每条是条目或条目对，不是操作说明书（操作说明进它长出的 skill）。候选检验按顺序收紧：不可约（先杀组合）→ 完整性（属是否已覆盖）→ 成对性（是否成对或对立端有去向）→ 生成性（能否冲出至少一种方法）→ 旧标准（可读性/有性状/是单个基因/只是基因不是说明书）。条目形态：优先一句含两极；只有一极有经典句时单极入列，对立端去向必须写明。每个环节至少一条；检验环节为手段×时点两条极。

## 层级：道 — 一 — 二 — 三 — 万物（gene-expression）

- **道**：未被切分的现实。没有对象、没有边界、没有先后。
- **一（对象同一性）**：道生一——从无限现实中确立「这一个」（问题化/域定）。同一性先于一切对立：对立面同出于这一个对象（同出而异名）。一不是句子，条目属于二。
- **二（条目对）**：对象内含差异，差异相激成对立；每条条目管一个环节，成对形态给出两极。对立既对立又统一（共有一个对象）。
- **三（skill）**：对立条目在环境里「冲」（clash）撞出的方法集。skill 是方法，不是承载它的文件。
- **万物（表型）**：skill 一次激活（activation）产生的实际行为与产物。

关键类比：条目＝基因型；skill＝由条目生成的方法；一次激活的行为与产物＝表型。方法、载体和激活都比条目更依赖环境，三者不能混称。

核心术语：对象同一性（问题化）、条目、条目对、极、属、skill、skill 载体、skill 激活、表达、冲、基因型/表型、哲学序列（清单本体）。

## 表达（expression）

**Thesis：表达是语义在使用关系中的保真变换。** 把有身份、来源与边界的语义对象，变换为接收者在具体环境中能理解、判断或行动的形式，同时保持那些会改变意义与行动的关系。

### 四项使用关系

不能由主题、作者偏好或"给谁看"单独推出表达形式，至少要同时恢复：

| 关系 | 核心问题 | 主要改变 |
|---|---|---|
| 受众 | 谁在接收，已知什么，何种词汇、权限与判断能力？ | 前提、解释深度、术语、例子、语气 |
| 目的 | 表达为什么存在，希望改变何种理解/判断/记忆/能力？ | 取材边界、重点、整体推进 |
| 行动 | 接收者实际要阅读、学习、查询、比较、决策、执行还是交给程序解析？ | 论证/步骤/表格/契约/schema 等操作形态 |
| 媒介 | 内容怎样到达、被检索、调用、更新和验证？ | 导航、层级、篇幅、结构化程度、维护方式 |

对载体形式选**最小真实形式**（不增加无主权威、重复维护、无用机制），不是最短文本或最低 token 数。

### 面向人与面向 Agent 的表达

- **面向人**：让读者恢复与目的相关的因果、对比、限定、递进、例证和结论；自然好读只是真实关系被顺畅理解后的表现。为顺滑而补出未经支持的动机/因果会得到表面完整、语义失真的文章。
- **面向 Agent**：不是更短更硬的人类文章。要显露真正改变判断和行动的条件：处理对象与期望改变、输入/来源地位/事实状态（指令/现状/候选/未知/仅供参考的区别）、允许效果与停止边界、判断标准与成功证据、返回给谁返回什么。结构化输出只在需要机械解析时占优；格式符合只证明格式，不证明事实正确、任务相关或已被接受。

### 双受众与单一语义源

人和 Agent 可以有不同的视图结构和篇幅，但必须从**同一个语义源**取得对象定义、事实状态、硬约束、权威与接受边界。单一语义源指一个语义事实只有一个明确的权威回答，不指所有内容在一个物理文件；派生视图是 projection，不因更便于消费而取得独立权威。单一来源只减少漂移，不保证来源正确。

### 承重语义先于 token economy

压缩前先确定哪些内容承担当前理解、判断或行动；删除后若改变以下任一项，它就是承重语义：对象身份、主张真值或强度、因果与优先关系、适用范围、证据归属、行动与效果边界、失败处理、接受判断。先保留承重语义，再压缩不承重的重复、礼仪性前言、无信息总结、无关背景和不能改变判断的例子。最好的表达是**足够且无无效负担**。

### 检验：文本质量由接收效果证明

表达是否成立回到它承诺的变化：人能否准确复述、判断或行动；Agent 能否在边界内完成正确变换并返回可解释证据；双受众面对同一事实变化是否保持语义一致。机械检查不能单独证明理解、语义忠实或行动正确。

## 概念形成与指称（concept-articulation）

**概念形成是让现实中的区别成为可共同判断的区别。** 从对象证据与处理目的出发 → 恢复哪些特征使对象相同或不同、与邻近概念的关系 → 可区分的定义 → 面向领域与受众的正式 designation → 行动中的区分检验。

- **对象、概念、定义与名称四者不能互相顶替**：已有名称不证明对象找对；罗列对象事实不等于形成概念；例子不等于定义；定义也不是对象本身。名称受概念边界约束，概念受对象证据约束；名称不穷尽对象。
- **关系形成边界**：概念边界由与其他概念的关系共同显现（上位、并列、外延、整体部分、关联）；最值得恢复的最近邻是最可能导致实际误判的概念。边界经受四个方向照验：包含、排除、最近邻、反例。
- **定义**：足够区分，不求说尽；「最小」服从「充分」——删决定性特征使边界坍塌，塞历史/实现/例子遮住概念身份。
- **临时 handle**：调查不能等概念稳定才开始时使用；正当性来自协调需要，不来自语义完成。必须保持三种边界：状态边界（明示 provisional，不冒充正式名）、作用域边界（只在命名范围内有效，指回对象证据与未知）、结论边界（不得预设类别/因果/价值/所有权，开始牵引证据就要替换）。临时 handle 是可抛弃的索引，不是较弱版本的 canon。
- **正式指称与行动检验（P14）**：主体遇到原本易混淆的实例时，名称与定义能否使其选对对象、责任、来源或下一步。改名但概念关系不变时行动应基本稳定；只有词语被喜欢、命名检查通过或解释读起来顺，不能单独证明概念成立。
