# Theory

本目录从归档 `.archive/` 中提取本项目的思想、理论与 harness 认知，作为新项目的知识沉淀。

- 旧项目文件全部保留在 `.archive/`；本目录是提取的要点与原文记录，不与归档同步维护；
- 提取遵循「忠实还原」：用户的原始思想保留原话（轻量润色不改语义），理论/harness 只提取要点；
- 需要追溯完整上下文、证据与处理回执时，回读归档的 `planning/`、`theory/`、`design/`。

## 读取建议

思想原典按主题拆分：处理哪类问题就读对应文件，避免一次读取全部。理论/harness 两个要点文件适合整体通读。
