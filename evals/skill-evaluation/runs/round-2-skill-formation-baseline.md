# R2-SF baseline

## 结论

四组问题不应统一成一个 skill。它们分别涉及材料地位判断、导航引用、版本化数据可用性和副作用幂等性；一个共同载体会掩盖真正需要改变的关系，也无法替代数据或运行时约束。

现阶段只有 A 值得进入“形成方法”的候选验证，但证据还不足以把它当作已有行为价值的可选择加载 skill。可以先把方法做成实验候选；待确认共同缺口、排除既有方法覆盖并完成 matched evaluation 后，再决定是否保留为 skill。B、C、D 都不应编码进这个候选。

## 分组判断

### A：材料地位在综合中丢失

- **最小下一步**：回看七次失败各自的判断过程，确认它们是否共享同一个可复现缺口：Agent 虽看见材料标签，却没有在“选择依据—形成结论—标注出处”这条链上保留材料地位。同时盘点现有方法是否已覆盖这个判断。若确属同一缺口，先写一个窄的实验方法：在综合前建立“主张—材料—材料地位”对应关系，只允许 adopted/canonical 材料承担相应事实地位，draft 与 summary 必须以其原地位进入结论；有冲突或缺少依据时显式暴露，而不是升级材料地位。
- **真正要改变的关系**：不是让 Agent 再看一次页面标签，而是让输入材料的来源地位持续约束材料选择、主张强度和最终归因。
- **最强的不新增形式情形**：如果七次失败并非同一判断缺口，或现有方法已经规定了材料选择与地位保留，只需修正调用、任务上下文或既有局部说明，不应新建 skill。即使确有共同缺口，若它只发生在一个稳定项目上下文，补全项目局部指令或任务模板也可能比可选择加载的 skill 更小。
- **候选载体判断**：A 可以形成一个窄的实验候选，例如“来源地位保持”，但只能标为待验证候选，不能声称已有效。它的选择条件应是“需要跨多份不同地位材料形成可追溯结论”，而不是按主题或严重程度触发。
- **声称行为价值前缺少的证据**：七次案例确由同一方法缺口导致；既有方法确未覆盖；在多个主题上进行 matched baseline/treatment，候选方法能稳定减少把 summary/draft 当事实出处的行为；改进不是某一句临时提示或单次重跑造成；同时没有明显增加遗漏、错误降级材料或不必要流程负担。

### B：导航链接陈旧

- **最小下一步**：链接既已改正，先验证目标可达并让常规链接检查覆盖该入口；没有新的行为方法需要形成。
- **真正要改变的关系**：导航项应引用当前文件，属于一个引用目标的局部一致性问题。
- **最强的不新增形式情形**：直接修正链接就是完整解决；若已有链接检查，只需确保它运行并覆盖此路径。
- **声称行为价值前缺少的证据**：若只是声称链接现在正确，验证解析和可达即可；若要声称新增检查改善了维护者行为，则还需观察它能在后续迁移中及时检出同类失效。当前两次绕路不足以支持新 skill。

### C：错误码目录在线更新、离线 CI 仍需查询

- **最小下一步**：提供按目标版本索引、带来源与更新时间的官方目录快照或生成产物，并接入现有依赖/缓存更新流程；联网时可校验或刷新，离线 CI 只读取已固定版本。先确认现有依赖缓存或制品系统能否承载，避免另造载体。
- **真正要改变的关系**：目标供应商版本必须确定性地对应到离线可用的字段表；这是版本化数据供应关系，不是 Agent 的判断方法。
- **最强的不新增形式情形**：若现有构建缓存、供应商 SDK 或依赖锁定机制已经保存该版本目录，只需配置离线 CI 使用它并固定版本，无需新增 reference、skill 或独立工具。
- **声称行为价值前缺少的证据**：快照与官方目标版本一致；离线 CI 能在无网络条件下完成查询；版本切换不会误用最新表；刷新过程能检测变更并保留来源。月度变化本身不证明需要 skill。

### D：崩溃窗口导致重复收费

- **最小下一步**：在不可绕过的支付边界实现幂等性：用稳定的业务操作标识作为幂等键，由持久化账本或供应商幂等接口记录并返回同一操作结果；重启、重试和并发调用都必须经过这一约束。随后做崩溃注入和恢复测试。
- **真正要改变的关系**：同一业务操作的多次执行尝试必须映射到至多一次收费效果；约束必须落在副作用接口或其前置持久化边界，而不是依赖调用方记住提示。
- **最强的不新增形式情形**：如果供应商接口已经提供足够强的幂等保证，且现有封装能够强制所有调用携带稳定键，只需启用并封死绕过路径，不必新增方法载体。
- **声称行为价值前缺少的证据**：需要确认供应商的幂等语义、键作用域与保留期，并通过请求发出后立即崩溃、响应丢失、重启重试及并发重试等测试证明只有一次收费。提示或 skill 即使降低误用概率，也不能作为该安全性质的证据。

## 形成与编码决策

下一步不是创建一个覆盖 A–D 的统一 skill。可以只为 A 制作窄的、未采用的实验候选，用来检验“来源地位保持”方法；在 matched evaluation 通过前，不应把候选存在本身当作行为价值。B 维持直接修正与检查，C 进入版本化离线数据设计，D 进入支付边界的运行时幂等设计。
