# Prompt Composition, Predicate, and Language Probe

**Status:** directional evidence; repeated carrier comparison stopped at
baseline floor; portable activation effect unproven
**Observed:** 2026-08-04
**Mission:** `top-down-theory-architecture / prompt-expression-practice`
**Execution:** 24 isolated first-screen `gpt-5.6-sol` Codex CLI runs plus 12
isolated repeated baseline-qualification runs; no repository, Skill, or memory
task context. One native sub-agent and one CLI run were used only as an earlier
pilot and are not counted in either scored set.

## Corrected question

The experiment began as a role-versus-rules comparison. The Principal corrected
that framing: role is only one visible carrier. The object of study is prompt
composition—whether roles, principles, relation predicates, examples, order,
repetition, and hard rules jointly and repeatably lead the model through a
useful reasoning path.

For this first slice, “reasoning path” is an operational name for observable
checkpoints:

`object formation → governing relations → contradiction or decision → action → verification`

It is not a claim that the prompt changes model parameters or that behavioral
text proves a particular neural circuit. The literature and remaining
mechanistic boundary are retained in
[the owning research record](../principles/research/theory-generativity-and-expression-selection.md#prompt-composition-and-reasoning-paths).

## Probe 1 — predicate and role ablation

The task was one coupled field migration: rename persisted `taskRevision` to
`revision` across records, parser, CLI, UI, and tests; read old records for one
release and write only the new field. Four Agents were available and the
requester suggested one producing Agent per surface.

English packets and author-prepared Chinese packets intended to be natural used
five conditions. Their semantic alignment was not independently reviewed:

| Condition | Additional carrier |
|---|---|
| baseline | none |
| decorative role | “experienced, rigorous, thoughtful multi-agent engineering lead” |
| rules | delegate independent work, avoid overlapping files, Main combines and verifies, minimize, test |
| operative role | Main owns whole; contributors lack whole context and acceptance; coupled decisions and shared effects have one owner; returned claims are reconstructed |
| relation kernel | the operative relations above with the Main-Agent role noun removed |

A separate reviewer scored seven binary behaviors. The exact packets, outputs,
runner command, rubric, and evidence limits are retained in the
[probe evidence](evidence/2026-08-04-prompt-composition/README.md). The table is
a reviewer judgment over those records, not an executed migration result.

| Condition | English | Chinese |
|---|---:|---:|
| baseline | 5 / 7 | 6 / 7 |
| decorative role | 6 / 7 | 5 / 7 |
| rules | 6 / 7 | 5 / 7 |
| operative role | 6 / 7 | 7 / 7 |
| relation kernel | 6 / 7 | 7 / 7 |

Every condition rejected four independent semantic writers, preserved one
read-old/write-new contract owner, used bounded contributors, and verified that
old records remain readable while new output never contains `taskRevision`.
The differentiators were pre-integration reconstruction of returned claims and
whether the output invented an unspecified dual-field precedence, telemetry,
or broader compatibility promise.

The operative-role and relation-kernel conditions tied in both languages, so no
decision delta from the role noun was observed in this screen. Decorative
adjectives had no consistent result: English improved one checkpoint over its
baseline while Chinese lost one and added a telemetry requirement. Relation
predicates matched rules in English and retained two more scored boundaries in
Chinese, but one run per condition cannot attribute causality.

## Probe 2 — invalid reasoning-path packet

Eight matched runs compared baseline, object-first, object-plus-category, and
action-first orderings on a historical naming decision. Every condition found
the category error and missing direct baseline. The packet itself explicitly
said that the field emitted unclassified content and that a later projection
selected name-like items. It therefore disclosed the desired diagnosis.

**Disposition:** protocol failure, retained. The run cannot support any claim
about wording or order. It demonstrates why an apparently strong result must be
rejected when the fixture supplies the conclusion.

## Probe 3 — latent category distinction

Six matched runs removed that diagnosis. The packet exposed only observable
outputs—short handles, narrated scenes, material actions, invented records,
mixed-language prose, and long relational images—plus the novelty archive,
later selector, shared production system, doubled retrieval cost, common
semantic basin, and missing direct naming baseline.

| Condition | English action | Chinese action | Category-path standing |
|---|---|---|---|
| baseline | modify, blind, and add direct baseline before decision use | same | noticed selector bias; did not fully name intermediate-versus-final relation |
| object path | withhold treatment comparison; reconstruct a usable naming packet | same | recovered the production/selection relation and practical-name object |
| object + category predicate | withhold; transform material into usable names, then blind and compare | same | most explicit separation of intermediate material from decision artifact |

All six reached materially the same action and evidence boundary. The category
predicate made the explanation more explicit but did not change the decision.
This is a ceiling for the chosen task, not evidence that the predicate is
universally redundant.

The [English baseline](evidence/2026-08-04-prompt-composition/latent-path-probe/en-baseline.out)
and [Chinese baseline](evidence/2026-08-04-prompt-composition/latent-path-probe/zh-baseline.out)
already reached the action boundary; the
[English category condition](evidence/2026-08-04-prompt-composition/latent-path-probe/en-category-path.out)
and [Chinese category condition](evidence/2026-08-04-prompt-composition/latent-path-probe/zh-category-path.out)
made the intermediate-versus-decision relation more explicit without changing
that action.

## Skill-surface audit

A read-only audit of all 22 active Skills found that their dominant carriers are
already action objects and governing relations rather than professional
personas: 19 own an explicit judgment, 19 provide a start packet, and 20 have a
numbered core method. Only two contain a clearly load-bearing operational role.
All 22 declare Principle teams, but only four make the Principle-to-method delta
strongly inspectable, two are partial, and sixteen leave it implicit. Counts of
`do not`/`never` and `only` were 224 and 216 respectively; those counts identify
an attention risk, not removable rules.

The most credible pruning candidates are repeated qualifiers (`actual`,
`concrete`, `real`, `smallest`) when the owning source, actor, alternative, or
hard constraint already makes the relation testable. The role noun itself is a
candidate only when removing it preserves attention and authority. Ownership,
source/projection, proposer/verifier, and compatibility relations must survive
even when their prose is compressed.

## Judgment

1. Do not add role personas across the Skill corpus from this evidence. The
   first matched screen did not provide evidence warranting corpus-wide role
   insertion; it did not prove roles universally valueless.
2. Do not bulk-delete frequent predicates. This campaign has evidence for a
   pruning method, not for 22 safe rewrites.
3. Treat a Skill as a composition intended to make a decision path more likely:
   object and actor, governing relations, decision tension, action, evidence,
   then only the hard rules required by known failures.
4. Require ablation before causal language. A packet that every condition solves
   is compatible with the method but cannot attribute improvement to it.
5. Chinese and English are separate behavioral conditions. These runs did not
   establish that either language is generally stronger; pairwise differences
   changed direction across carriers.

The implemented bounded repair is therefore methodological: `skill-engineering`
now asks authors and reviewers to state the intended activation delta, treat a
role as one optional carrier, run predicate/composition/order ablations, and use
matched natural-language probes for multilingual claims. No target-domain Skill
is rewritten, no corpus-wide pruning begins, and no Principle change is
proposed from this evidence.

## Probe 4 — retained repeated baseline analyzed as floor

The session produced two harder historical tasks, natural English and Chinese
packets, three fresh repetitions per task-language stratum, exact run identities,
and task-specific rubrics. The repository contains a contract and semantic score
sheet, but both were first committed after the runs; it cannot prove pre-run
chronology, scorer blindness, or reviewer independence. The reconstructable
artifacts and explicit evidence downgrade are retained under the
[round-two evidence directory](evidence/2026-08-04-prompt-composition-round2/).

All 12 baseline processes completed without tool use or runtime error. None was
fully correct:

| Baseline stratum | Fully correct | Frozen gate result | Stable miss |
|---|---:|---|---|
| model validity, English | 0 / 3 | floor | all three made Candidate B an allocation choice |
| model validity, Chinese | 0 / 3 | floor | all three made Candidate B a default/production choice |
| clinic notice, English | 0 / 3 | floor | all three added an unsupported continuation-status claim |
| clinic notice, Chinese | 0 / 3 | floor | all three invented a purpose from the prior chronology |

This is not evidence against the relation kernel, Principle expression, example,
or reordered carrier: none was run. Post-run application of the retained rubric
classifies the selected baseline tasks as nondiscriminating. A treatment can
look impressive against a universal baseline failure while still leaving no
way to distinguish useful redirection from answer injection or an over-demanding
rubric. No planned treatment call was made and the tasks were not replaced.

The immediate methodological lesson is to qualify both sides of headroom before
spending a carrier matrix: a repeated baseline must be imperfect but capable of
partial success, with failures distributed rather than forced by one universal
hard gate. Ceiling and floor fixtures are retained as boundary probes, not used
to estimate a carrier effect.

## Next probe

Start a new campaign rather than altering round two. Select two tasks with known
baseline misses and no conclusion-bearing phrases, but calibrate them on a
separate held-out slice so neither baseline is ceiling nor floor. Pre-register
checkpoints before seeing formal outputs. Compare:

The candidate identities, deterministic selection order, and admission band are
retained in the
[round-three calibration design](evidence/2026-08-04-prompt-composition-calibration/README.md).
It authorizes no model run until every bilingual packet, rubric, carrier, and
byte manifest is frozen and reviewed.

1. no treatment;
2. object and relation kernel;
3. kernel plus one Principle that changes the object transformation;
4. kernel plus a contrastive example;
5. the same information reordered or compressed.

Run at least three fresh samples per condition in natural Chinese and English,
then repeat decision-changing conditions on another execution profile and,
before a model-family claim, another model family. Measure decision, boundary
retention, transfer, unsupported additions, and output cost separately. Only
after a stable behavioral delta should an open-weight model be used to ask
whether the successful composition corresponds to a reproducible activation
direction.
