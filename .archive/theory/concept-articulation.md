# 概念形成与指称

> 本文是活树理论。证据与采纳判断见
> [`theory/research/concept-articulation.md`](research/concept-articulation.md)。本文解释概念如何从对象证据中形成、
> 如何由定义进入正式指称，以及名称为何不能反过来支配对象；它不新增哲学序列条目，也不规定固定写作模板。

## 定位与血统

**结构前提：对象同一性。** `gene-expression.md` 所说的「一」先从未分现实中确立「这一个」。概念形成不替代
这次问题化，而是在已经可指认的对象上恢复特征与关系，使相关主体能够稳定地区分和行动。

**主血统：P14（名不正则言不顺）。** 名不是装饰；名实错位会让实践主体误判对象、责任或行动。P14 位于
解决·表达环节，所以正式名称的终点不是词语漂亮，而是使所需区别进入实践。

**支持血统：** P01 与 P02 约束对象和概念必须有来源与证据；P04 要求未定边界保持为真未知；P05 要求概念
服从具体领域、目的和粒度；P06 防止把对象的全部事实都塞进定义；P15 要求定义与名称最终接受行动检验。
这些条目在概念形成与指称的问题环境中相冲，生成本文的方法关系；本文不是哲学序列的新条目。

## Thesis

概念形成与指称不是给一个已有词补解释，而是让现实中的区别成为可共同判断的区别。它从对象证据和处理目的出发，
恢复哪些特征使对象相同或不同、它与邻近概念处于什么关系，再用定义说出足以区分的边界，最后选择正式
designation（指称）。正式名称成立以后，还要看它是否让目标主体在真实场景中作出正确区别。

```text
对象证据与目的
  → 概念特征、外延与关系
  → 可区分的定义
  → 面向领域与受众的正式 designation
  → 行动中的区分检验
```

这是生成依赖，不是不可回返的流水线。候选名称可能暴露缺失的邻居，反例可能迫使对象重新问题化，行动失败
可能要求重写定义。但回返不能倒置权威：名称可以帮助调查，不能要求证据迁就名称；载体可以承载概念，不能
取得概念同一性。

## 对象、概念、定义与名称

对象是现实中可感知或可设想、在本次问题处理中被确立为「这一个」的东西。概念是关于对象的知识单元：它以
一组相关特征和概念关系，使一个对象或一类对象可被认识。定义把这些特征表达出来，并使该概念与相关概念
可区分。designation 则是在特定领域中用语言或符号指向概念；一般概念可以用 term，个别概念可以用 proper
name，代码标识符和文件名则是特定载体中的指称。

四者不能互相顶替：已有名称不证明对象已经找对；罗列对象事实不等于形成概念；例子不等于定义；定义也不是
对象本身。一个概念可以更换名称而保持关系，一个名称也可能在不同领域指向不同概念。因而，名称必须受概念
边界约束，概念必须受对象证据约束。

**名称不穷尽对象。** 名称只选择足以让目标主体稳定指向和区分的少量特征；对象仍有未被本次概念化的性质，
也可能在新目的下形成另一种合法概念。把名字当成对象的本质，会把当前视角冒充完整现实；把名称携带的评价、
因果或所有权当成事实，则会在调查开始前藏入结论。

## 关系形成边界

概念不是孤立标签。它的边界由与其他概念的关系共同显现：它属于哪个直接上位概念，在同一划分标准下与哪些
并列概念相邻，哪些对象或下位概念落在其外延中，当前说的是整体还是部分，以及哪些只是因果、时序、使用或
协作上的关联。共同出现或字面相似不能代替这些关系。

最值得恢复的「最近邻」不是名字最像的东西，而是最可能导致实际误判的概念。一个边界至少要经受四个方向的
照验：

- **包含**显示哪些典型实例和边界实例因何属于它；
- **排除**显示最近非实例缺少哪项区分特征；
- **最近邻**显示共同上位概念与决定性差异；
- **反例**命名什么观察会迫使当前概念拆分、合并或重做。

这四者是概念边界的证据，不要求全部挤进一句定义。例子、范围说明和反例各自保存不同信息；把它们压成短句，
可能让定义看似简洁却失去区分力。

## 定义：足够区分，不求说尽

定义的任务，是用最小但充分的特征把概念同相关概念区分开。通常可以从直接上位概念与区分特征开始，但形式
服从概念关系：开放集合不能伪装成穷尽枚举，整体—部分关系不能写成类属关系，当前文件实现也不能冒充能力
本身。仅把名称换成同根词、宣传语或宽泛用途，没有建立新的区别。

「最小」服从「充分」。删掉不改变区分的内容，是 P06 所要求的损；删掉决定性特征只是为了短或节约 token，
会使边界坍塌。反过来，把对象的历史、实现和所有例子都写入定义，也会让偶然事实遮住概念身份。定义留下的，
应是目标判断真正依赖的差异；其他说明可以进入解释、证据或例子。

定义也不取得终局权威。它是关于概念边界的候选主张，必须保留来源和未知，并能被新对象证据、邻近关系或
行动结果修正。

## 临时 handle

调查和协作不能总等到概念稳定后才开始，因此可以先给材料一个临时 handle。它的正当性来自协调需要，不来自
语义已经完成。临时 handle 必须保持三种边界：

1. **状态边界**：明示它是 working/provisional 指称，不冒充 preferred term、正式名称或已接受定义；
2. **作用域边界**：只在命名的调查或协作范围内有效，并指回对象证据、未知和待区分邻居；
3. **结论边界**：不得以名称预设类别、因果、价值或所有权，一旦它开始牵引证据就应被替换。

临时 handle 因而是可抛弃的索引，不是较弱版本的 canon。概念边界、定义、目标受众与区别用途稳定后，它可以
被正式 designation 取代；若它值得保留，也只能作为检索别名，不能形成第二语义源。

## 正式指称与行动检验

正式 designation 要与概念种类、领域和受众相称，并让同一讨论范围内的指向保持稳定。它不必把定义压缩进
词形，也不追求脱离语境仍唯一正确；它要避免与最近邻共享一个会导致误判的标签，也不能用新奇或审美掩盖
概念空缺。

P14 的行动含义在这里完成：当主体遇到原本易混淆的实例，名称和随附定义能否使其选对对象、责任、来源或
下一步？改名但保持概念关系不变时，行动应当基本稳定；只给名称而没有对象证据和关系时，诚实结果应是无法
恢复边界；只有词语被喜欢、文件通过命名检查或解释读起来顺，都不能单独证明概念已经成立。

实践结果可以否定当前概念边界或指称，却不会让一次成功自动成为普遍真理。局部任务中的区分成功支持该领域和受众中的
适配；要扩大适用范围，仍需新的对象证据与反例检验。

## 与 skill、写作和 harness 的边界

本文拥有的是**概念形成的解释区分与生成关系**：为什么对象证据先于概念，关系怎样使定义可区分，正式名称
为何晚于边界而接受行动检验。未来 `concept-articulation` skill 若成立，负责在具体环境中把这些关系表达成
Agent 可采用的方法、探针和返回；skill 的一次成功不反过来证明理论正确。

写作拥有的是如何按受众、目的和媒介，在既定载体内组织已经形成的意义。它可以调整顺序、例子、篇幅和语气，不能为了流畅
重写概念边界。形式选择拥有的是内容是否需要新载体、应成为何种载体，以及普通的文件名与目录落点检查；
载体变化不移动概念的证据或权威。

Harness 负责把人的任务重建为有界 Agent 工作并保持效果、证据与接受关系。概念形成与指称可以帮助它区分 Task、
Run、verification 或 authority，却不能仅靠改名创设生命周期、权限或接受权威。若所需性质必须在混乱提示词、
并发或恢复中强制存活，问题已经越过概念与 skill，属于 base 或适配器。

## 修订纪律

先修具体概念，当对象证据、邻近关系或行动失败表明边界不成立；修相应 skill，当代表性任务显示理论区分正确、
但 Agent 未能恢复或表达它；改本文，只有当证据改变了对象—概念—定义—designation 的解释关系。一个坏文件名、
一次误称或某供应商偏好不单独构成理论变更证据。

本文不提议新增哲学条目、全局 glossary、ontology、命名委员会或固定术语流程。只有重复失败证明普通文档与
现有方法无法保持必要关系时，才重新研究新的 skill、载体或机制。
