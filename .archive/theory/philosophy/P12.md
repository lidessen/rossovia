# P12 reading candidate：知彼知己，百战不殆

状态：`source-current / reading-candidate / research-open / independent-review-complete / conditional-revision-applied / follow-up-clean / acceptance-pending`；不是哲学源行、living theory、对抗策略、信息政策、runtime 规则或实现授权。

本文件只从现行哲学序列的 P12 源行重建 reading candidate。它把 P12 放在解决阶段的对抗·知环节，
不把历史 archive 的战略解释直接当作当前语义，也不把“百战不殆”写成成功保证。

## 源与对象

唯一源是 [`theory/philosophy.md` P12](../philosophy.md#L29)：

> P12｜知彼知己，百战不殆｜解决·对抗·知

P12 回答的是：当问题包含真实的对抗关系时，行动前如何同时认识对方和自身，使后续应对不只从
单方面视角出发。这里的“彼”和“己”是对抗关系中的两个对象范围，不是把 P12 拆成两个独立
条目；它也不是一般的调查、问题边界或已知/未知表达。

## 最小定义与边界

在当前问题处理领域，P12 的暂定定义是：

> 面对一个会因彼此行动而改变的对抗对象，在选择应对前，同时恢复与当前应对问题有关的彼与己
> 关系，并只把相称证据支持的关系带入下一项应对判断。关系可以涉及目标、能力、约束、可观察
> 事实或未知，但具体要恢复什么由当前对象、允许效果和证据决定，不构成固定的信息清单。

这一定义保留“知彼知己”的关系性：只知道自身会把局部判断误当全局，只观察对方而不认识自身
也无法判断可行效果。它不规定必须收集哪些数据、取得什么权限、使用什么侦察工具或达到什么
置信度；“百战不殆”在本 reading 中是该关系可能带来的结果方向，不是对任何战斗或任务的保证。

### 最近邻

- **P02「没有调查，没有发言权」**回答一般认识是否有相称调查和证据；P12 只在对抗关系中要求
  同时照看彼与己，不能把 P12 变成普遍调查门槛。
- **P04「知之为知之，不知为不知」**约束每一项关系的已知/未知表达；P12 不允许用“了解对方”
  的措辞掩盖未知，也不因有未知就停止所有有界判断。
- **P08「井蛙不可语海，夏虫不可语冰」**处理对象、视域和适用范围；P12 的彼/己是对抗关系
  中的对象，不是把对方视域直接等同于 P08 的边界问题。
- **P13「避实击虚」**回答掌握对抗信息后如何选择应对；P12 提供知的前置关系，不替 P13 选择
  响应方向。
- **P09「抓住主要矛盾」**回答同一对象内何者会改变其他冲突或下一判断；P12 不能把对方信息
  自动写成主要矛盾或优先级。
- **P15「实践是检验真理的唯一标准」**回答主张如何面对相称实践；P12 的信息恢复不等于已经
  通过实践检验。

### 包含、排除与反例

- **包含：** 一个系统发现存在会反应的竞争性 consumer 时，同时记录对方可观察约束和自身
  可用 effect，再决定是否提出有限 response candidate；缺少一侧时保留 unknown，不假装完整。
- **排除：** 没有真实对抗关系时，为了覆盖 P12 而把普通多来源 planning、provider comparison
  或 owner/Agent 分工称为“彼己”；这会把关系范围扩大成空泛口号。
- **排除：** 把 P12 解释成获取秘密、默认监控、攻击策略、越权侦察、拒绝对方或防御性 runtime
  policy；这些都需要独立的 authority、effect、security 和 acceptance 关系。
- **反例：** 只依据自身计划推断对方意图，或只依据对方的一次可见动作推断其全部能力；若
  两种材料都不足却给出确定应对，P12 与 P04 的共同边界被击穿。

## 生成性候选

当 P12 与一个有真实对抗关系的 Agent/工作环境冲撞时，可以长出“彼己对照的 bounded situation
map”候选：只恢复当前应对问题所需的彼己关系，并在关系仍不充分时保留多个有限应对假设，供
相应的 research、planning 或 evaluation owner 形成下一判断。这个方法当前最多支持创建或更新
有来源的研究/计划/评估 artifact；它本身不取得影响判断、获取信息或施加 effect 的权限，也不
生成默认情报系统、攻击策略、资源调度器、权限扩大或 runtime routing。
