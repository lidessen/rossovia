# P04 reading candidate：知之为知之，不知为不知

状态：`source-current / reading-candidate / independent-review-complete / acceptance-pending / research-open`；不是哲学源行、living theory、skill 载体或 runtime 规则。

本文件只解释现行源中的 P04，不把“unknown”扩成评分、拒答协议或接受门。它与 P01/P03 父 item

## 源与对象

唯一源是 [`theory/philosophy.md` P04](../philosophy.md#L13)：

> P04｜知之为知之，不知为不知｜认识·已知边界

P04 回答认识阶段的边界问题：面对一个对象和当前认识，什么可以称为已知，什么必须如实保留为
未知。它要求表达状态与证据相称，不用“看起来合理”、材料存在或他人曾说过来填补尚未成立的
认识。

## 最小定义与边界

在当前问题处理领域，P04 的暂定定义是：

> 只把当前证据能够支持的对象、关系或结论称为已知；对证据不足、来源身份不明、关系尚未
> 建立或结果尚未观察的部分明确保留未知。在需要继续推进的上下文中，缺口可以另行附上，但
> 可回返方向不是“知/不知”成立的强制条件。

这里的“知”不是模型置信度数字，也不是接受决定；“不知”也不是无条件拒绝行动。P04 只约束
认识状态的诚实表达和边界可供后续判断恢复，不取得调查资格、实践检验、接受、权限或 runtime
owner。在需要继续推进的 planning/eval 上下文中，可以另附缺口和可能的回返方向；没有立即可行
的下一项时，仍可诚实保留 unknown，不能把“可回返”变成 P04 的强制行动条件。

### 最近邻

- **P01「实事求是」**回答认识从哪里取得来源并寻求规律；P04 回答当前哪些规律已经有足够
  支持可以称为已知。材料来源正确不等于规律已成立。
- **P02「没有调查，没有发言权」**回答材料/调查不足时是否取得发言资格；P04 表达已知/未知
  状态，不能把“未知”自动改成“不许发言”，也不能用发言资格代替状态判断。
- **P03「实践、认识、再实践、再认识」**回答实践和新观察如何改变下一认识/实践；P04 可以
  让未知成为下一实践的对象，但不规定循环本身或固定回合。
- **P08「井蛙不可语海，夏虫不可语冰」**回答问题边界与视域限制；P04 关心当前认识状态，
  不把对象范围、受众视域或上下文不可通约直接写成“我不知道”。
- **P15「实践是检验真理的唯一标准」**回答检验手段；P04 不声称主张已经通过实践检验，
  也不取得 acceptance authority。

## 包含、排除与反例

- **包含：** 当前 WorkCell 设计明确知道 `Spec → Binding → RunRequest` 的设计 baseline，
  但对 active Binding revocation、Event replay 和 retry lineage 仍分别保留 unknown；记录已知
  与未知，不把设计候选写成协议事实。
- **排除：** 只因为 archive 中有某字段、provider 有某 session 或历史记录曾给出某结论，便
  称 living design 已知；这混淆了来源、历史参考和当前证据。
- **排除：** 在需要交接的 planning/evidence record 中只写“未知”却不说明对象和缺口，不能
  作为足够的边界记录；但这不意味着没有立即行动时 P04 就禁止保留 unknown。
- **反例：** 若材料不足、来源身份不明或关系未观察，候选仍断言确定结论，P04 边界被击穿；
  若已有可回读证据却仍把结论写成未知，说明当前定义或证据链需要回修，而不是一律扩大 unknown。
- **父 item 反例关系：** 有材料不等于已知（P01/P04）；有实践结果不等于已完成检验（P03/P15）；
  检验时点被检查也不等于下一判断已经改变（P03/P16）。

## 生成性候选
