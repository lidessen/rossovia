# P13 reading candidate：避实击虚

状态：`source-current / reading-candidate / research-open / independent-review-complete / conditional-revision-applied / follow-up-clean / acceptance-pending`；不是哲学源行、living theory、攻击策略、绕过规则、runtime router 或实现授权。

本文件只从现行哲学序列的 P13 源行重建 reading candidate。它处理解决阶段对抗·应的 response
选择；P12 的“知”是它的相邻前置，但 P13 不因此取得任何信息、权限或 effect。

## 源与对象

唯一源是 [`theory/philosophy.md` P13](../philosophy.md#L31)：

> P13｜避实击虚｜解决·对抗·应

P13 回答的是：在对抗行动中，不必把响应预先锁定在同一正面位置；如何根据已知关系比较不同
响应方向。“实”和“虚”在本 reading 中只是待具体 domain/owner 复核的关系性标签，不是源行
直接给出的固定分类，也不是把真实/虚假、正确/错误或保密/公开直接等同起来。阻力、代价、
后果或可恢复性只是可能帮助区分响应方向的观察维度，不能未经复核直接定义“虚”。

## 最小定义与边界

在当前问题处理领域，P13 的暂定定义是：

> 在已恢复的对抗对象、允许效果和当前约束内，比较不同响应方向对当前目的、阻力、代价、后果
> 和可恢复性的影响；当具体 domain 的证据显示某一方向更符合目的且可止损时，把它提出为有限
> response candidate，同时保留替代项、未知和重新判断条件。

“避”不是无条件逃避，“击”也不是必须造成伤害；这句话只提供一种 response 关系。它不规定
“实/虚”的固定指标，不要求欺骗，不允许绕过权限或安全约束，也不把一次选择写成永远正确。

### 最近邻

- **P12「知彼知己，百战不殆」**回答对抗前如何同时认识彼与己；P13 使用相称的知来选择应对，
  不能在没有 P12 类信息或其它来源支持时凭空判断“实/虚”。
- **P09「抓住主要矛盾」**回答同一对象内哪一矛盾会改变其他冲突；P13 选择对抗响应方向，
  不把“较弱阻力”自动写成主要矛盾。
- **P10「为之于未有，治之于未乱」**回答介入时机；P13 不是提前介入规则，即使方向较弱也
  仍需判断何时行动。
- **P07「天下难事，必作于易」**回答形成可行入口；P13 的“虚”是对抗关系中的 response
  方向属性，不是一般任务的易处。
- **P11「治大国若烹小鲜」**回答解决阶段如何控制扰动和成本；P13 可以考虑代价，但不取得
  扰动预算、资源分配或执行频率 authority。
- **P04「知之为知之，不知为不知」**要求对“实/虚”的依据和未知诚实；未知不能被包装成虚弱点。

### 包含、排除与反例

- **包含：** 在存在两个或多个会产生不同后果的对抗 response 时，比较各自对允许 effect、阻力、
  代价和可恢复性的影响，选择较小且可观察的局部响应，再根据结果调整。
- **排除：** 把 P13 直接变成攻击、欺骗、漏洞利用、绕过 host/security policy、拒绝服务、
  资源抢占或自动选择 provider；这些必须由独立 authority、policy 和 acceptance 决定。
- **排除：** 把任何低成本、非主路径或不熟悉的工作都叫“虚”；若它与 accepted purpose、
  consumer 或实际 effect 没有关系，就不是 P13 的对抗响应。
- **反例：** 只因为某一方向看起来容易就采取行动，却没有观察对方反应、实际效果或失败代价；
  这把“避实击虚”降成了未经检验的偏好，不能支持 P13 的 standing。

## 生成性候选

当 P13 与真实对抗环境冲撞时，可以长出“基于已复核观察的 bounded response branching”候选：在
P12 或其它相称来源支持的情境图上列出少量响应候选，比较其可观察后果和回退条件，把结果交给
相应 owner 判断继续、改向、停止或回 owner。它可以支撑 planning/research/eval 的 response
comparison，但不形成通用攻击策略、自动防御器、runtime scheduler 或权限规则。
