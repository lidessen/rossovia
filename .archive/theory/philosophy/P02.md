# P02 reading candidate：没有调查，没有发言权

状态：`reading-candidate / source-current / independent-review-complete / acceptance-pending / research-open`；
不是哲学源行、living theory、skill 载体、拒答规则或 runtime 权限。

本文件只解释现行源中的 P02，不改写源行。它承接 P01 的“认识从何处取得来源”，进一步判断在
材料/调查不足时，一项断言或结论是否取得相称的证据资格；它不把“发言权”扩成沉默要求、社会
权限或接受门。

## 源与对象

唯一源是 [`theory/philosophy.md` P02](../philosophy.md#L9)：

> P02｜没有调查，没有发言权｜认识·证据

当前对象是“针对一个对象或问题作出事实性断言、结论或处置建议时，调查/证据是否足以支持这项
发言”。这里的调查不是固定步骤、必须亲自执行的工具调用或完整收集所有背景，而是与当前断言
直接相关、能够使证据资格发生变化的材料取得和核对关系。

## 最小定义与边界

在当前问题处理领域，P02 的暂定定义是：

> 对对象作出需要证据支持的断言或结论前，应先取得与该断言相关的调查材料；材料尚未取得、
> 来源身份不明或调查不足时，可以提出问题、报告已观察到的局部事实或标记待调查事项，但不
> 应把未经调查的结论当作已有证据的发言。

这一定义保留“调查→发言资格”的因果关系，同时把发言区分为观察、问题、假设、证据性断言和
接受/处置决定。P02 约束的是证据资格，不决定什么算最终已知、谁拥有 domain acceptance、是否
必须继续调查或是否停止行动。

### 最近邻

- **P01「实事求是」**规定认识从实际对象和来源材料出发并寻求规律；P02 进一步规定没有相关
  调查时不能取得对该对象作结论的证据资格。P01 不自动推出调查门槛，P02 也不替代对象来源。
- **P04「知之为知之，不知为不知」**表达当前认识状态的已知/未知；P02 关心取得发言资格所需
  的调查关系。调查不足时可以把状态如实标为未知，但“未知”不等于 P02 的全部，也不自动禁止
  提问或报告局部观察。
- **P03「实践、认识、再实践、再认识」**说明新实践如何改变下一认识与实践；P02 不规定循环、
  重试或固定调查回合，只判断当前断言是否已有相关调查支撑。
- **P15「实践是检验真理的唯一标准」**回答用什么实践检验主张；P02 可要求先有相称调查，
  但不声称调查已经检验主张，也不取得 acceptance authority。
- **P08「井蛙不可语海，夏虫不可语冰」**关注问题/视域边界；P02 关注证据资格。调查范围不明
  时应先承认 scope unknown，不能用 P02 把视域限制写成普遍沉默。

## 包含、排除与成对案例

- **包含：** 在审查 WorkCell protocol 是否发生 source drift 前，先读取当前 canonical source、
  记录算法和比较对象；若只看到旧记录中的 hash 而未核对算法，不能断言 protocol 已漂移。
  本例只支持“该断言尚未取得证据资格”，不证明协议接受或 source owner 的决定。
- **包含：** 在判断一个 archive skill 是否值得迁移前，先恢复其正文、当前 consumer、最近邻和
  真实行为证据；没有 consumer 时可以提出 candidate-next，但不能断言它已经是 portable skill。
- **排除：** 提出“需要调查什么”的问题、报告“我看到文件 X 存在”的局部观察或明确标为
  `hypothesis`，不等于未经调查作出结论；P02 不禁止这些低强度表达。
- **排除：** 调查材料存在但与当前断言无关，不能因此取得发言资格；材料数量、工具调用次数或
  文档篇幅也不能替代相关性。

### 成对案例

1. **证据改变资格：** 案例 A 只看到一条旧 planning 记录，未核对当前 source；案例 B 读取
   当前 source、确认 hash 算法并复核记录。A 可以报告“尚未核对”，不能断言 source drift；B
   才取得讨论 drift 的证据资格，但是否接受结论仍交给 owner。
2. **局部观察不等于总体结论：** 案例 A 观察到一个 `.agents/skills/` 文件格式正确；案例 B
   还核对真实 consumer、行为差距、匹配 probe 和 portable 边界。A 可以报告 format observation，
   不能断言 skill 已接受；B 才能进入 skill-formation review，但仍不自动取得 acceptance。
3. **问题不等于结论：** 案例 A 提出“是否需要 replay consumer”；案例 B 在没有 consumer 的
   情况下断言“Event 可以重放”。前者是可保留的调查问题，后者超出了当前调查资格。

## 生成性候选

当 P02 与 Agent/planning/evidence 环境冲撞时，可以长出“先取得与当前主张相关的证据，再决定
是否拥有断言资格”的方法。它可支撑 source review、evidence audit、skill-formation 或
`agent-expression`，但不成为通用 research gate、拒答策略、调查队列、权限机制或 acceptance
authority。P02 也不能替代 P04 的 unknown 表达、P01 的 source identity 或 P15 的实践检验。
