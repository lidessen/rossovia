# P08 reading candidate：井蛙不可语海，夏虫不可语冰

状态：`reading-candidate / source-current / independent-review-complete / acceptance-pending / research-open`；
不是能力判定、权限拒绝、跨域通信禁止、问题路由器或 runtime scope 机制。

本文件只解释现行源中的 P08。它处理分析阶段的问题边界与视域条件：一个观察、判断或表达只在
其对象、范围、时间和语境被指明时才有可回读的意义；范围外不能直接沿用，但也不能因此被偷换成
“已知为假”或“永远不可沟通”。

## 源与对象

唯一源是 [`theory/philosophy.md` P08](../philosophy.md#L21)：

> P08｜井蛙不可语海，夏虫不可语冰｜分析·问题边界

本 reading 不把源行的形象化表达扩成主体能力、智力或权限结论。当前 living 序列只给出它在
问题处理领域中的坐标：先辨认问题/观察的视域和适用范围，再判断是否能在相同条件下传递或需要
重新问题化。

## 最小定义与边界

在当前问题处理领域，P08 的暂定定义是：

> 明确一个问题、观察或结论所覆盖的对象、视域、时间和语境；若接收方或新问题不共享这些条件，
> 不直接把原结论外推过去，而是标记边界、补充条件或重新调查。边界不等于永远不能沟通，也不
> 等于范围外事实已经被判定为 unknown、false 或 forbidden。

P08 的对象是问题的适用范围与跨范围传递条件，主要判断是“这个结论在哪些条件内成立，跨出去后
   需要怎样重新说明”。它不决定主体能力、不发放权限、不拒绝任务、不取得 acceptance 或 runtime
   routing authority。

### 最近邻

- **P04「知之为知之，不知为不知」**区分当前证据足以称知与仍未知；P08 区分问题/观察覆盖到哪里。
  范围外可以是尚未提出的问题、需要重新调查的对象或暂不适用，不自动等于 P04 的 unknown。
- **P05「具体问题具体分析」**判断哪些特殊条件会改变分析；P08 先界定哪些对象和条件属于当前
  问题，不能以“具体”替代 scope boundary。
- **P07「天下难事，必作于易」**选择可行入口；P08 判断入口或结论的适用范围，不能把入口大小
  写成 scope。
- **P09「抓住主要矛盾」**处理多个矛盾的主次；P08 可以限制结论的适用域，但不取得全局优先级。
- **P12「知彼知己，百战不殆」**未来若进入真实对抗 consumer，处理自/他两侧信息范围；P08
  当前只处理问题边界，不生成对抗策略、资源分配或 hostile runtime。

## 包含、排除与成对案例

- **包含：** WorkCell planning 中，一条 replay/lineage 观察只覆盖已指明的 record、时间段和
  source；若要用于新的 consumer，先检查是否共享这些条件，并把缺失的映射或重新调查保留下来。
- **包含：** 一个跨视域 handoff 可以先返回“此结论只适用于当前 binding/host 条件”，再决定是否
  需要补充事实或建立新的 claim；这是边界说明，不是拒绝接收。
- **排除：** 因为一个 consumer 不在当前 scope，就断言它没有能力理解、没有权限访问或永远不能
  沟通；这些是不同的能力、授权或系统关系，不能从 P08 源行推出。
- **排除：** 把 scope 外内容直接标为 P04 unknown，或把当前 scope 内的局部结论写成全局事实；
  应分别标记“未覆盖/需重问题化”和“证据不足/unknown”。
- **排除：** 用 scope boundary 代替 P09 的主次判断、P07 的入口选择或 P05 的特殊条件分析；
  边界只能说明“在哪里问/适用”，不能单独决定“先做什么”。

### 成对案例

1. **范围内：** 同一个 WorkCell Binding、同一 record contract 和同一时间覆盖内，replay identity
   的观察可以支持限定断言；它仍不等于 accepted replay contract。
2. **跨范围：** 将该观察直接用于另一个 host、不同 Binding 或不同时间窗口；正确动作是保留
   scope 差异并重新调查/映射，而不是直接复用，也不是宣布对方不可沟通。
3. **scope 与 unknown 分离：** 当前问题明确只问“某条 record 是否存在”，而没有问 retention
   或 replay gap；后者是未被问题覆盖，不能未经提问就写成“已知 unknown”或已解决。
