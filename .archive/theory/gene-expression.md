## 问题：skill 表达不稳定

skill 是指导 Agent 工作的方法集合。它的载体和激活处在表达层，会随环境变化；这种不稳定来源有二：

1. **外因，表达漂移。** 各大模型提供商的系统提示词、模型版本更新，会让同一方法在不同运行环境里措辞、步骤、优先级漂移。skill 载体的文字与结构一换，激活后的表达也会变。
2. **内因，冗余表达。** 一个 skill 载体虽然写了一堆，本质仍是少数条目在某个场景下生成的方法。载体再多，追根都是少数条目的具象；它们之间的差异很大部分是场景与表达差异，不是条目差异。

由此得：**条目是基因型；skill 是由条目生成的方法；skill 的一次激活所产生的实际行为与产物才是表型。** 方法、载体和激活都比条目更依赖环境，但三者不能混称。注意类比的边界：基因型→表型只解释「条目如何经方法在环境中产生具体行为」；「道→一」是现实→对象的层级，不在遗传类比里——一不是基因，它不表达，它只确立对象。

## 层级：道 — 一 — 二 — 三 — 万物

用《道德经》四十二章的骨架记录这个层级。它不是寓言，而是本项目从理论到方法到产物的实际结构。

### 道：未被切分的现实

现实本身是无限的、未分的。它没有对象、没有边界、没有先后——不是「混沌」作为一个东西，而是还没有任何东西被确立。方法论的起点不在道里，而在离开道的那一步。

### 一：对象同一性——确立「这一个」

道生一：第一步是从无限现实中确立一个对象。把「一件事」从现实中切出来，给它边界、给它身份，使它成为「这一个」——可指认、可追问、可处理。这一步叫**问题化（域定）**。

一不是对象的具体内容，而是**同一性本身**：

- **同一性先于一切对立。** 没有「同一个东西」，就没有「两面」：「知」与「不知」之所以对立，是因为它们关于同一个认识对象；「增」与「损」之所以对立，是因为它们作用于同一个活动；「多源」与「单源」之所以对立，是因为它们说的是同一件事的来源。**对立面同出于这一个对象**——《道德经》第一章「同出而异名」。一提供的不只是一个对象，而是对立得以成立、得以成对的共同基底。
- **同一性不能由任何一句「二」说尽。** 任何条目对都只是「这个对象」的一个视角；把视角当成对象，就把一降成了二。所以一不是句子——条目属于二；一是对象的身份，只能被完整论述：现实可分、对象可确立、对象确立后内含差异、差异相激成对立、对立同出于这一个对象。这里没有矛盾：**「一被论述」不等于「一成为条目」**——本文关于一的文字是对层级结构的说明（元层），哲学序列里的话才是条目（对象层）；条目都是「这同一个对象内部的对立」的主张，关于一的话不是这种主张。
- **「现实可分可把握」只是「一」的后承，不是「一」。** 它是世界观前提，但可知论是「一」成立之后才谈得上的，它不能反过来代替一。

由此，「道生一」在方法论上就是**问题化**：无限被收敛成「同一个东西」。没有这一步，后面的一切——对立、方法、产物——都没有落点。

### 二：对立统一的条目

一确立后，对象不再浑一：它内含差异。差异相激，成为对立：实事与本本、调查与空谈、实践与认识、知与不知、特殊与普遍、主与次、名与实、彼与己……每一对对立共有一个对象（同出），所以既对立又统一——这就是**条目对**。注意边界：能由这些对立组合生成的（快与慢、多源与单源、增与损、现场与中枢……）不是条目，是**方法**——它们属于三，由条目在环境里冲撞而生。

先约定几个词，后面不再解释：

- **极**：条目对的一端。「知」与「不知」各是一极。
- **属**：一极离开它的对立面就不成其为一极——没有「不知」，「知」就只是「知道某事」，不是认识边界；没有「慢」，「快」就只是速率，不是节奏。两极共同定出**属**（旧称「方向」）：知×不知定「认识的边界」，增×损定「繁简」（分析·简化），少动×多动定「扰动代价」（解决·成本）。**属 = 对象上的一个刻画坐标**，由一对对立极共同界定；属清单即环节表的坐标侧，随着哲学序列维护在 `theory/research/philosophy-gene-one.md`（15 环节，见「生成指引」环节表）。
- **成对**：一个条目的对立极已经找到，且两极同出于一个对象。成对有三种承载：
  - **一句对偶**：一句经典自带两极（「兼听则明，偏信则暗」一句含多源、单源两极）——优先；
  - **两条条目**：两极各有经典句，分别入列（「知彼知己」与「避实击虚」构成知×应对）——次选；
  - **一条+解读**：对立极没有经典句，单极句入列，对立端记在解读或候选中——不得已。

「单句不完备」因此指：一条单极句（如「抓住主要矛盾」）只写出属的一半，需要另一极完成该属；不是说单极句不能入列——当另一极没有经典句时，它以单极入列，由哲学序列整体承担「属完整」的责任，解读里必须写明另一端是什么。

**同一属已有条目时的处理**：属是坐标，一个属只取一个原子。候选与现有条目同属时，要么证明现有条目不是原子（更原子的候选替换它，并写出替换论证），要么承认并入——进现有条目的解读，不重复收录。

**属的判定是语义的，不是程序的**：判定「候选句回答的坐标是什么」，靠解释与论证（评审时写清），不靠算法。注意并非每条经典句天然是条目对——「知彼知己」里彼与己不是对立极（是知的对象范围），它是否成对、属于哪个属，要在候选评审里论证，不能先验归入。

条目对还可以嵌套：「实事求是」内部即是一对——实事（材料、静）与是（规律、动）相激又相生；对外又与「本本」构成对立。

### 三：skill——对立在环境里「冲」出的方法

对立条目只规定属，不是方法。方法来自对立在环境中的**冲撞**：实事涌入与求是推理相冲，长成检索补全（RAG）；已知与新知相冲，长成反思校正；目标与现状相冲，长成规划。对立不是被逻辑合并，而是在境遇里摩擦、妥协、磨合，长成具象方法——**skill = 对立条目 × 环境里的冲撞**。这一步解释了为什么同样几个条目能长出花样繁多的技能：不是条目多，而是每个环境都让对立冲一次。

生成完成以后，条目与环境形成的判断关系应当已经内化进 skill 方法，并由 skill 载体完整表达。条目编号可以留作生成血统、审计、诊断和再生入口，却不是一次 skill 激活的运行时依赖：普通使用者不应为了执行方法再回读条目。只有在修订方法、诊断漂移或重新生成载体时，才沿血统回到条目与理论；当前任务自身的事实来源仍按任务需要读取。

### 万物

skill 加工对象，产出提示词、流程、模板、评估，以及一次一次的具体行为。万物最终又成为下一个任务所面对的现实内容——它们**不是道**（道依然未被切分），而是使现实变厚的素材；下一个对象的「道生一」，从这片素材里重新切出。

```
道（未分的现实） → 一（对象同一性：从道中确立「这一个」） → 二（对立统一的条目） → 三（skill：对立在环境里冲出的方法） → 万物
```

原初的想法是「从道中提炼道理，道理是一；由道理生成 skill，skill 是二」（当时尚无一物曰「条目」）。修正后：条目是二；**一不是条目，是对象同一性，只能以完整论述写出**；由二的冲撞生成三（skill），三生万物。「道生一」的开口由此关闭：一＝问题化／域定，不是一条警句。

## 为什么条目值得单独保留

1. **可再生。** 有了条目，即使 skill 方法及载体全部消失，也能根据具体情景重新生成方法并编码新载体。条目层是基因型，激活后的具体行为与产物是表型。
2. **抗漂移。** 模型更新、系统提示词变化首先改变载体适配和激活表现，不改条目层。把稳定的东西放在条目层，把易变的东西放在方法表达层，两者不再互相拖垮。
3. **可诊断。** 一个 skill 载体或激活表现不好，维护者可以沿血统回看：方法由哪些条目生成，是生成时没有内化关键关系、载体没有完整表达方法，还是具体环境使激活失真。这个回看属于修订与诊断，不转化为普通使用者的前置步骤。
4. **可再生地组合。** 同一批条目在不同环境里冲撞，长出不同的 skill 方法；同一方法可以编码为不同载体，并在不同环境中产生不同激活结果。差异的根源在冲撞与场景，不在重复造条目。

## 范围：只聚焦问题处理

不是所有条目都要整理。这些条目聚焦**问题处理领域**：怎么分析问题、怎么解决问题。所以它是认识论与方法论（实事求是、辩证法、具体问题具体分析、主要矛盾……），而不是处世哲学大全。

战略与战术、策略也在这个范围内：**孙子兵法值得挖掘**——知彼知己、避实击虚、以正合以奇胜、先胜后战、将在外君命有所不受……它是「问题处理」在对抗性、资源性场景下的成熟方法论库。

## 生成指引：认识 → 分析 → 解决，三段推导序列

五条标准是**检验式**的（筛掉不对的），坐标表是**校准式**的（检查偏属），但都不解决「下一句该找什么」——那是**生成式**问题。框子来自项目自己的定义，三句话：**怎么认识问题、怎么分析问题、怎么解决问题**。段落之间是先后关系，不是并列标签；每段有必答环节，**环节有限、闭环，序列靠环节生成，不靠大海捞针。**

**生成链：**

```
问题处理（范围）
 ├─ 认识问题（是什么）：来源 → 证据 → 如实 → 深化 → 已知边界
 │    事实从哪来、凭什么说、怎么如实照、一次够吗、知道多少算知道
 ├─ 分析问题（什么结构）：特殊性 → 简化 → 入手点 → 问题边界
 │    与一般什么关系、怎么删繁就简、从易处还是难处下手、问题划到哪、对方视域
 └─ 解决问题（怎么做成）：主次 → 时机 → 成本 → 对抗 → 表达 → 检验
      先解哪个、何时动手最便宜、花多少代价、对手环境如何对待、
      如何让实践主体行动、是否真正解决

每个环节＝一句必答题；每句必答题＝序列中的一条
环节之外的需求（注意力、计划、风险）＝环节之间的组合 → 三，不进序列
由「一」回答的问题（目标、范围）＝问题化本身 → 不进序列
```

**环节表（序列因此生成）：**

| 段 | 环节 | 必答问题 | 序列 | 状态 |
|---|---|---|---|---|
| 认识 | 来源 | 事实从哪来？ | 实事求是（实事×本本） | ✓ |
| 认识 | 证据 | 凭什么说？ | 没有调查，没有发言权 | ✓ |
| 认识 | 如实 | 怎么如实照？ | 用心若镜，不将不迎（《庄子·应帝王》） | 解读 |
| 认识 | 深化 | 一次够吗？ | 实践、认识、再实践、再认识 | ✓ |
| 认识 | 已知边界 | 知道多少算知道？ | 知之为知之，不知为不知 | ✓ |
| 分析 | 特殊性 | 与一般什么关系？ | 具体问题具体分析 | ✓ |
| 分析 | 简化 | 怎么删繁就简？ | 为学日益，为道日损（损之又损） | △ 重判 |
| 分析 | 入手点 | 从易处还是难处下手？ | 天下难事，必作于易（63 章；「细」半句进解读） | ✓ |
| 分析 | 问题边界 | 问题划到哪、对方视域？ | 井蛙不可语海，夏虫不可语冰（秋水；缺陷由解读补「拘于虚/笃于时」） | ✓ |

| 解决 | 成本 | 花多少代价？ | 治大国若烹小鲜（60 章） | ✓（与 P06 判词：分属分析/解决两阶段，语义同源，靠阶段切割） |
| 解决 | 对抗·知 | 如何知彼知己？ | 知彼知己，百战不殆（谋攻） | ✓ |
| 解决 | 对抗·应 | 如何对待对手？ | 避实击虚（虚实） | ✓（与知面构成知×应对） |
| 解决 | 表达 | 如何让实践主体行动？ | 名不正则言不顺 | ✓ |
| 解决 | 检验 | 是否真正解决？ | 实践是检验真理的唯一标准（手段极）+ 慎终如始，则无败事（时点极） | ✓ |

**三个问题的判定：**

- **为什么需要**：环节存在 → 环节必须被回答 → 回答它的最经典句就是序列。候选若不属于任何环节的必答题，就是三（组合）或一（问题化），不进序列。
- **缺什么**：环节表即账本。当前缺口：成本（待调研）、对抗（待挖据）、检验第二极（待复议）；「为道日损」从成本挪到简化是本次三段框架的修正。
- **哪里不准**：句子回答的不是它所在环节的问题，即错位；句子是环节之间的组合，即三。例：P01「原则高于规则」——不在任何环节的必答题上（工具层级）→ 三；「兼听则明」——回答的是证据环节的执行细节（多信息源），不是环节本身的问题 → 三。

**两个层各司其职：** 环节表（生成层，指引"下一句找什么"）；坐标表（校准层，检查"这一句偏没偏属"）。坐标表不再作为选句依据，只作为校验。

## 对哲学序列梳理的含义

本文改变哲学序列的性质与检验方式，执行放到下一步：

- 哲学序列不是「警句收藏」，是**方法论的条目集**：每条是条目或条目对，不是操作说明书；操作说明应当出现在它长出的 skill 里。
- 候选检验按顺序（自上而下收紧）：
  0. **不可约（先杀组合）**：能否由现有条目组合生成——能，就不是条目，是方法，进解读或 skill，不进序列；
  1. **完整性**：这个属是否已有条目覆盖；
  2. **成对性**：它是否成对——一句对偶自带两极，或与另一条条目成对，或对立端已写明在解读/候选；
  3. **生成性**：它能否在某个环境里冲撞出 skill（至少举得出一条可写出的方法）；
  4. **旧标准**（这五条不是「警句收藏的趣味」，而是**基因的可用性**）：脍炙人口（中文能单独站住、语料成片共现——决定模型是否自带正确联想，即基因的**可读性**）；能生（解读、方法、约束可从它长出）；能判（换成别的句子，以后有一类选择会变——决定它是否**有性状**）；不可约（不是两条经典或经典加一段手册的拼接——决定它是否**是单个基因**）；一行（没有藏起来的操作步骤——决定它是否**只是基因，不是说明书**）。
- 条目形态：优先一句含两极（对偶句）；只有一极有经典句时，单极句入列，但对立端必须写明去向（解读/候选），不得假装完整。一条条目的落笔格式：`Pxx｜句子`；解读中写明属、两端（若成对）、对立端去向（若单极）、至少一个生成性示例（可冲撞出的方法）。
- **「一」＝对象同一性**：完整论述在本文，哲学基础源文件的引言指向它；哲学序列只承载「二」。
- **环节—条目规则**：每个环节**至少**一条；检验环节为手段×时点两条极；认识·如实（用心若镜）无独立经典句入列，明文由解读承担；「每条一题」的严谨表述是「一环节一问、一问可有极的两面」。
