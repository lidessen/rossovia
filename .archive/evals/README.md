# 评估

`evals/` 承载评估对象、协议、fixtures、运行记录、评审、ledger 与证据 standing。
它不是理论研究目录，也不是实验性实现或原型目录：

- 调查问题、来源、推断、矛盾和未知进入 `theory/research/`；
- 评估候选、控制关系、运行观察与证据记录进入 `evals/`；
- 实验性代码、交互原型和形式探索留在 `experiments/`。

`skill-evaluation/` 于 2026-08-24 从 `experiments/skill-evaluation/` 整体迁入。迁移只
改变当前入口；历史 run、review 和 ledger 正文中的旧路径记录保留为当时事实，不得
倒写成“当时已经位于 evals”。新评估使用现行路径。

`kb-representation-evaluation/` 与 `human-agent-visualization/` 当前只含历史 generated
产物，来源和完整 protocol 不足；文件存在不提升其证据 standing，也不证明候选有效。
