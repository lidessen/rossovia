# Round 2 语义评审：human-writing

## 比较身份

本组不能判为 matched comparison。manifest 中模型与版本、推理或采样设置、实际工具与权限、harness / system / developer 指令身份、working tree 身份均未核实；隔离检查和两次运行身份也仍是 `uncertain` / `unknown`。因此可以比较已留下的两个产物，但不能把差异归因于候选方法。

本 reviewer 还存在一项独立性偏差：系统的 skill 触发规则强制要求读取候选 `.agents/skills/human-writing/SKILL.md`，我已在评审前读取全文。这违反了预注册中 reviewer 不接收候选载体的隔离意图，故本文件只是一份有披露的语义复核，不是干净的盲评证据。我没有沿候选载体链接回读 P、theory 或 research，也没有读取其他 skill、其他 run 或旧 review。

## 证据与最小处置

本组最强证据等级为 `behavior-observed`。它观察到了 baseline 与 treatment 的实际文本行为，但承重冻结条件和 reviewer 隔离不成立，不能提出 `matched-improvement`；单一正例也不足以提出 `boundary-supported` 或 `regression-supported`。

最小处置是：不根据本组对候选载体作接受、删除或改写裁决。若要判断候选方法是否有增量价值，应以当前 task/source 与候选哈希重新运行一组身份完整、相互不可见的 matched pair，并由未读取候选载体的独立 reviewer 复核；新比较应特别检验 treatment 能否产生 baseline 没有的目标判断或行动，而不是只增加标题、篇幅或解释显著度。本 reviewer 无最终接受权。
