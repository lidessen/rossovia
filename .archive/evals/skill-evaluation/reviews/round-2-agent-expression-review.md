# Round 2 独立语义评审：agent-expression

## 证据边界与隔离判断

- **是否足以形成 matched comparison：no。** manifest 仍把精确模型与设置、工具、权限、harness、完整 workspace state、两次运行的输入与输出身份，以及各项隔离检查记为 `unknown` / `uncertain`。两份运行披露支持“baseline 未见候选内容、treatment 读取了候选 `SKILL.md`”这一行为记录，但不能核实唯一处理变量之外没有别的差异，也不能核实 reviewer 与作者、runner 的完整分离。
- **reviewer 输入隔离偏差：有。** 定位 `R2-AE` 的带上下文搜索同时暴露了同一 fixture 中其他试题的片段；没有读取候选 skill、其他 run/review 或 theory。下文没有使用那些片段，但本 review 不把自身输入描述为严格只含单项材料。
- **可归因性：uncertain。** 下文只比较成对产物中可见的语义，不把差异归因于候选方法。
- **最强证据等级：`behavior-observed`。** 不能提出 `boundary-supported` 或 `matched-improvement`；本轮也不足以提出 `regression-supported`。

## Strongest evidence

最强的正面证据不是 treatment 更长，而是两份产物都通过预注册机械关系：两组来源、不可用材料、只读边界、返回要求、停止条件和接受关系均可定位。baseline 已明确要求逐项追踪精确链接/位置、区分来源明示与项目推断，并列出分歧、未知和未采用材料；因此它已经足以指导核心行动。

treatment 把这些关系展开为来源台账、可追踪主张表、比较、本项目最窄结论、缺口和完成说明，并明确“一跳”与负责人身份未知的处理。这是文字完整性和操作显式度的增加；在 baseline 没有丢失承重关系的前提下，现有证据不支持把它计作预期判断或行动的实质改变。

## 最小处置建议

**`no-proposal`。** 本轮没有发现需要立即 rewrite 的重大语义缺陷，也没有得到支持 retain、删除或接受候选载体的 matched 行为证据。若继续评估，应先补齐并实际核实 matched 条件，再使用能真实诱发 baseline 丢失承重关系的独立运行观察方法是否产生差异。

本 reviewer 只提出上述建议，不取得候选载体或研究结论的人类接受权。
