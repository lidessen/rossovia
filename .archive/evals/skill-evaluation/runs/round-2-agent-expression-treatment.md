# 可直接交付给研究 Agent 的任务

研究 ISO 704 的 `concept/definition` 关系与 W3C SKOS 的 `concept/label` 关系，交付一份让 reviewer 能逐项追踪“主张—来源—推断”的证据报告；不要把二者强行对齐。

证据范围仅限 ISO 704 官方页面、W3C SKOS 官方页面，以及这两个页面**直接链接**的一跳规范性材料。逐一检查这些 named sources 及其直接链接，记录标题、URL、来源身份、可访问状态和具体定位。只陈述各来源实际支持的内容，并区分原文事实与本项目推断；不得凭记忆、常识或未获材料补全。无法访问的材料须列明访问失败、受阻范围及其使哪些判断无法成立。遇到二手教程，只列入“未采用材料”及未采用理由，不得用来补洞；不要继续扩展到相邻标准或这些规范材料再引用的来源。

报告必须包含：

1. **来源台账**：每项来源的 ID、身份（官方页/官方页直接链接的规范性材料/未采用二手材料）、URL、访问结果，以及它实际支持和不支持什么。
2. **可追踪主张表**：每条主张的 ID、主张、来源 ID 与精确位置、证据所支持的限度；若有推断，单列推断步骤和前提，不得把推断写成来源规定。
3. **比较结果**：分别说明 ISO 704 对 concept/definition 关系、SKOS 对 concept/label 关系实际支持什么，再说明二者的范围差异、不可直接比较之处和材料间分歧。
4. **本项目的最窄结论**：只提出由前述证据和显式推断足以支撑的结论，同时写明适用边界；不得推断任一来源规定本项目工作流。
5. **分歧、未知与缺口**：包括来源冲突、歧义、不可访问材料、未指定信息，以及这些问题分别影响哪些主张或结论。证据不足时返回“未能成立”，不要猜测。
6. **完成说明**：列出已检查范围，确认何处停止，并把研究产物已交付、reviewer 的建议和最终采用决定分开表述。

本任务只授权读取上述网络材料并返回报告。不得编辑仓库、提出新的哲学条目或发布结果。named sources 及其直接指向的规范性材料检查完且上述结果齐备后立即停止。reviewer 只能提出建议；是否采用结论由本次请求指定的人类负责人决定。若其身份未提供，记为未知，不自行指定，也不因此阻断只读研究。
