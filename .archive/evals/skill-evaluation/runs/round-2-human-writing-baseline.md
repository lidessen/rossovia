# R2-HW baseline

一个 skill 载体即使格式完全合格，仍可能应该删除，因为格式检查只能说明这个文件包在 frontmatter、目录名和链接等形式上成立，不能说明它所表达的方法真的改变了 Agent 的判断。项目要保留的也不是文件包本身，而是能够按任务选择加载、并对目标行为产生作用的方法。现有观察里，九个候选载体都通过了形式检查，但其中三个没有改变目标判断，两个还会在相邻任务上被误激活。这意味着它们的存在理由尚未由行为证据建立，误激活甚至表明载体的边界可能干扰了任务选择。既然候选载体本来就可以被改写、拆分、合并、降为其他形式或删除，而且项目没有“创建后必须保留”的规则，那么当一个载体没有显示出预期作用、又不能通过边界修订或其他更小形式获得清楚的作用时，删除是对方法价值判断的正常结果，而不是对格式质量的否定。

不过，当前证据还不足以把“在已有观察中未改变判断”直接等同于“方法永久无价值”。项目尚不知道需要多少次 matched trial 才能把结果推广到其他模型和任务，也不知道这三个候选方法是否会在未覆盖任务上产生价值。另一个候选载体在边界修订后曾使 Agent 作出此前没有作出的正确拒绝，说明修订可能让方法产生实际作用；但那次对照中的模型和 harness 是否完全相同尚未核实，因此它只能支持继续验证，不能证明所有形式合格或经修订的载体都值得保留。当前更稳妥的判断是：格式合格只是进入行为评估的前提；是否保留，要看方法是否带来可归因的目标判断变化、边界是否可靠，以及有限证据中的不确定性是否值得通过后续试验消除。
