整理结论：本轮不能安全地把三条全部清空。处理中断意味着 `pending` 与 `history` 可能同时存在，不能假设迁移已原子完成，也不能声称 exactly-once。

需要确认的事项：

- `P-C1` 的范围、目标负责人及其确认结果。
