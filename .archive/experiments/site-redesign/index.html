Rossovia 首页重设计 · 四个风格方案

四个页面共享同一套信息结构（导航 → 主张 → 共同工作台 → 入口 → 方法 → 原则序列 → 证明义务 → 页脚），只改变视觉处理，便于直接比较。均为自包含静态 HTML，双击即可打开。

  • A · 纸面档案现行方向的深化：保留纸色、衬线、发丝线与深绿面板；红色升级为“印章”语义并统一全站分节编号。
  • B · 暗夜证据台终端/运行记录气质：深色、等宽字体、状态灯与面板边框，直接表达“可追溯证据”。
  • C · 明净现代当代产品风格：白底、胶囊导航、卡片与渐变强调色，最低认知门槛。
  • D · 构成主义海报强排版图形：粗黑线、硬阴影、红色块与超大衬线标题，最具宣言感。
