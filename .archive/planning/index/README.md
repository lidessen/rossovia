# Planning working indexes

这里保存帮助当前 planning 选择、解释和回读工作的 supporting views。它们不是第二份 roadmap、item ledger、
Plan、Todo 队列或 acceptance source；当前 standing 回到 [`../item-ledger.md`](../item-ledger.md)，方向和
顺序回到 [`../roadmap.md`](../roadmap.md) 与 [`../plan.md`](../plan.md)，具体语义和证据回到各自 canonical source
与 [`../records/README.md`](../records/README.md)。

## 读取方式

普通任务先读 [`../README.md`](../README.md) 和 item ledger 当前部分；只有当前 work map 的选择需要某一
working view 时，才从下面进入。working index 提供信息 scent、交叉索引和当前分析，不拥有它引用的事实。

| view | 用途 | 不拥有 |
| --- | --- | --- |
| [`candidate-consolidation.md`](candidate-consolidation.md) | 候选对象、consumer、owner、standing 和处置集中发现 | 各 candidate 的语义、acceptance 或实现授权 |
| [`coverage-audit.md`](coverage-audit.md) | P01–P16 与跨 item 关系 coverage | philosophy source 或 reading acceptance |
| [`evidence-maintenance-review.md`](evidence-maintenance-review.md) | evals/experiments 的 evidence standing 与 applicability 路由 | eval protocol、Run 或实验结论 |
| [`item-ledger-field-audit.md`](item-ledger-field-audit.md) | item contract 字段结构覆盖 | item ledger 的 current standing |
| [`item-loop-coverage-audit.md`](item-loop-coverage-audit.md) | 16 个 item 的 B/O/D/R/A/P/G 闭环覆盖 | item 完成、acceptance 或 adoption |
| [`skill-migration.md`](skill-migration.md) | archive/living skills 的迁移与处置索引 | skill carrier acceptance 或 portable promotion |
| [`whole-planning-work-estimate.md`](whole-planning-work-estimate.md) | 当前整体工作图与发现分支 | 预算批准、优先级或执行队列 |
| [`whole-work-coordination-candidate.md`](whole-work-coordination-candidate.md) | 跨 item wave、fan-in、checkpoint 的方法候选 | runtime scheduler、priority 或 acceptance |
| [`research-application-coverage.md`](research-application-coverage.md) | research result 到下游 carrier、activation、adoption 与 archive gate 的辅助对账 | research authority、adoption registry、自动 loader 或 runtime guarantee |

working index 的位置只表达“这是辅助当前读取的视图”，不表达 standing、优先级、owner、完成或接受。
没有 decision delta 时，不因 index 目录存在而新建或补齐 view。
