# 面向人的写作

把已经形成且有来源边界的意义，写成一个具体的人在具体场合能够恢复的理解。不要从喜欢的文风、现成大纲、标题数量或所谓“人味”开始。先恢复这个读者从哪里出发、这次阅读要改变什么，以及来源允许文字把他带到哪里。

这个 skill 的主要判断是：

> 给定一个来源有界的语义对象，以及具体读者、目的、场合和既定媒介，怎样选择、排列、连接和展开意义，才能让读者准确理解、判断或行动，同时不补造来源没有支持的关系，也不让篇幅与 token 偏好删掉承重语义？

写作结果应当是一篇真实可用的表达，而不是对写作规则的复述。方法服务于整体意义推进；标题、列表、段落、例子和语气只是按实际关系选用的手段。

## 理论来源

以下 living theory 是生成本方法的语义来源：

- [`theory/expression.md`](../../../theory/expression.md) 确立表达的保真变换、面向人的理解关系、承重语义与接收效果检验。

[`theory/research/expression-and-form.md`](../../../theory/research/expression-and-form.md) 只保存生成期间使用的公开证据、archive 经验、反例、供应商环境限制与未知，不拥有本方法的语义。[`evals/skill-evaluation/protocol.md`](../../../evals/skill-evaluation/protocol.md) 只拥有行为对照、边界 fixture、证据级别与收敛条件等评估契约。

主要血统是 P01、P05 与 P14：来源约束可以说什么，具体读者与场合改变怎样说，表达使真实关系进入人的理解与实践。P02、P06、P08、P09、P11、P15 和 P16 分别约束证据、删减、问题边界、主次、成本、接收效果与回归。只有当这些关系改变写作判断时才需要指出血统；列出条目编号本身不是写作依据。

P 条目只记录本方法的生成血统；living theory、research 与 protocol 分别保留语义来源、生成证据和评估契约，standing 不同。它们都不是普通 skill 激活的前置阅读。本 skill 载体已把写作判断内化在下文，普通激活只凭本文件完成写作；只有维护者在修订、诊断或重新生成载体时才沿链接审计。写作对象的事实与材料来源仍须按当前任务读取。

## 使用边界

在语义对象、主要来源与承载形式已经足够稳定，而工作缺口是“怎样让这个人理解、判断或行动”时使用本 skill。典型对象包括理论说明、分析文章、决策理由、教学内容、操作说明、维护者文档和受空间限制的界面文字。

不要用它接管相邻判断：

- 对象、概念边界、定义或正式名称不稳时，交给 `concept-articulation`；自然的文字不能替不清楚的对象制造确定性。
- 尚未决定文章、表格、reference、skill 载体、计划或其他载体时，交给 `form-selection`；本 skill 在既定形式内写作。
- 需要让 Agent 选择工具、改变对象、遵守效果边界并返回证据时，交给 `agent-expression`。
- 需要维护人类视图与 Agent 视图的共享语义核和同步关系时，交给 `dual-audience-expression`。
- 事实调查、机制强制与最终接受仍分别属于来源研究、runtime 或明确的接受者。

一次句子润色若不涉及可重复的理解关系，可以直接完成，不必展示整套方法。若来源、读者或目的缺失到无法判断取舍，应明确缺口并暂停相应主张，不要以流畅补全掩盖未知。

## 恢复写作关系

先建立足以约束写作的工作理解，而不是先拟标题。至少恢复以下关系：

1. **语义对象与来源状态。** 哪些是已接受事实、定义、观察、推断、候选、他人观点或未知；哪些来源拥有当前权威；范围、时间和成熟度到哪里为止。
2. **读者起点。** 这个具体读者已经知道什么，可能误解什么，采用什么词汇，能作何种判断或行动。不要用宽泛角色标签替代这些可操作的差异。
3. **目的与到达点。** 阅读为什么现在发生；完成后，读者需要理解什么关系、形成什么判断或能够做什么。目的可以只是建立理解，不必强加行动号召。
4. **场合。** 文字处在怎样的对话、决策、学习或协作阶段；读者为何此刻关心；风险、时间和既有争议怎样改变解释深度。场合不能成为补造动机的许可证。
5. **媒介边界。** 既定形式怎样被阅读、扫描、查询、更新或受空间限制；哪些外部契约不可改变。媒介影响实现，不改变来源事实。

写下这些关系只为支撑取舍，不要求把它们原样暴露给读者。能够从当前材料稳定恢复的低风险前提不必重复；一旦某个假设会改变结论、范围或行动，就应显式标明。

## 守住主张边界

写作中的连接本身也是主张。因果、动机、先后、对比、目的、成熟度、价值判断和必然性都需要来源或清楚标记的推断，不能因为它们让文章更顺滑就自动成立。

逐项检查将要成立的关键主张：

- 事实与引述能否回到具体来源，主张强度是否超过证据；
- “因此”“但是”“首先”“为了”等连接所表达的关系是否真的存在；
- 例子展示的是实例、边界、机制还是类比，是否被误写成定义或证明；
- 范围、条件、例外、反例与时间状态是否被概括吞掉；
- 推断、建议、价值选择和未知是否被伪装成既定事实；
- 作者是否因追求完整叙事而为人或组织补写未经支持的意图。

来源相互冲突时，保留冲突及其归属；证据不足时，写出当前能成立的较弱主张和需要什么才能推进。不要用含糊的被动语态或无主语断言隐藏责任，也不必给每个常识句添加妨碍阅读的出处。可追溯程度应与争议、风险和主张新颖度相称。

## 形成整体推进

完整表达不是把事实分别装进若干标题。先确定读者必须经过的理解路径：他从哪个问题或已有判断进入，哪些关系必须先建立，哪一个困难、区别或证据推动下一步，最后能得到什么有边界的结论。

按这个路径组织材料：

- 开始部分让读者看见真实对象、当前问题和阅读价值，不用空泛预告代替内容。
- 中间部分围绕少数主要关系推进。每个段落应承担一个对整体有作用的变化，例如提出主张、给出依据、解释机制、建立对比、处理反例或展示例证。
- 相邻部分要能回答“为什么此处之后是彼处”。若任意换序仍毫无影响，检查它们是否只是目录式并列，或者本来就属于可独立查询的 reference。
- 结尾抵达目的所要求的理解、判断或行动，并保留条件、未知和接受边界；不要仅复述标题，也不要凭惯例添加与正文无关的总结。

这不是强制三段式。查询型 reference、变更记录、词表、按钮和错误消息可以有意保持条目独立或极短；论证、解释与教学通常需要连续推进。是否采用 prose、列表、表格、步骤或小标题，取决于它们能否保持真实关系和当前媒介中的可用性，而不是某种表面形态天然更像人写。

## 展开论证、例证与未知

当目标需要读者接受一个判断时，不能只陈列结论和证据。让他看见证据怎样支持该结论、采用了什么前提、哪些替代解释被排除或仍然存在，以及结论在何种条件下会改变。重要的反对意见应在会影响判断的位置处理，不要集中放进装饰性的“局限”章节。

例子应服务一个明确关系：帮助读者识别实例、跨过抽象门槛、观察机制或看见边界。选择最少但足够的例子；相似例子不能替代独立证据，生动类比也不能偷偷扩大结论。若反例会迫使主张缩小、拆分或重建，应让它进入正文判断，而不是在脚注中消失。

未知也属于完整表达。把未知放在它实际限制主张或行动的地方，并说明这是未调查、证据冲突、开放选择，还是暂不可知。只有确实影响读者下一步时，才展开研究需求；不要把所有可能问题罗列成免责清单。

## 写成自然而准确的文字

自然表达来自关系清楚，而不是避开某些词或模仿随意口吻。使用读者能理解且不损失区别的词汇；术语第一次出现时只解释本次阅读所需的部分。句子长短、段落密度和语气随意义与媒介变化，不以统一风格制造表面一致。

作者声音只能来自可观察的立场、词汇和判断习惯。材料不足时，保持朴素、直接且适合场合的语气，不宣称恢复某种人格。不要用“AI 味”词语黑名单、标题计数、列表比例或破折号清理代替语义修订；这些表面特征只有在妨碍理解时才需要局部调整。

## 在完整与成本之间修订

先辨认承重语义，再压缩。删除一处内容若会改变对象身份、主张真值或强度、因果与优先关系、适用范围、证据归属、判断依据、下一步或未知状态，就不能仅为简洁、篇幅或 token 经济而删掉。

在此之后，删除不能改变理解、判断或行动的重复、礼仪性前言、无信息总结、无关背景、泛泛鼓励和多余例子。合并能够保持关系的句段，把主结论放在读者能找到的位置。安全说明、教学和高风险决策中，为降低错误或帮助恢复而保留的重复可能是承重内容。

“正常完整表达”也不许可无限展开。每段都应对当前目的有工作；过长造成的注意稀释、冲突、截断和维护成本是真实损失。目标不是最长或最短，而是足够且没有无效负担。

## 从接收效果检验

先做来源对照，再从读者一侧复查：

- 读者能否准确复述主要主张、依据、范围和未知，而不是只记住漂亮结论；
- 需要判断时，他能否解释证据与结论的关系并识别重要替代项；
- 需要行动时，他是否知道下一步及其条件，又没有获得未经授权的保证；
- 文章整体是否把他从真实起点带到预期到达点，局部结构是否服务这条推进；
- 媒介中的导航、密度和长度是否让所需内容可找到；
- 精简后承重语义是否仍在，扩写后是否真的降低误解或改善行动。

代表性行为探针至少包括：把一组有来源的主张写成面向指定读者的连贯解释并保留不确定性；面对未定义对象时拒绝用文章补造概念；面对 Agent 执行任务时转交给相邻 owner；在短界面文字和长论证两种媒介中都不机械套用文章结构；在上层偏好短输出时仍保存会改变理解的限定和依据。

运行仓库机械校验只能报告 `format-valid`。更强主张依照 [`evals/skill-evaluation/protocol.md`](../../../evals/skill-evaluation/protocol.md)：冻结模型、任务、原始来源、工具、媒介与工作区，比较不加载候选 skill 载体，和只加载该载体并发生一次 skill 激活的结果；分别测试发现与激活后的行为；由独立且能看见来源的 reviewer 判断保真、推进、读者适配与比例。

只采用实际成立的最强证据级别：

`format-valid` → `behavior-observed` → `boundary-supported` → `matched-improvement` → `regression-supported`

自评、表面更顺、一次成功或读者偏好都不能单独证明方法有效。

## 交付

默认交付可直接给目标读者使用的成品，而不是写作检查表或方法报告。除非任务要求，推理过程不应盖过文章本身；但会改变读者判断的来源状态、关键假设、未知和接受边界必须进入适当位置。

若无法完成，准确返回缺失的来源、读者关系或既定形式，以及该缺口阻止了哪项主张或组织判断。若完成，说明已做的实质性改写、仍存在的材料限制和实际验证级别即可。不要把“文字已写完”等同于来源正确、读者已经理解或最终内容已被接受。
