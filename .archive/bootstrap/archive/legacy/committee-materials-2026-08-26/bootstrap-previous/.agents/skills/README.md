# 临时班子 skill 入口

本目录当前没有 active skill。临时班子的实际能力直接采用本项目工作流中的根 canonical skills，并通过
[`../../AGENTS.md`](../../AGENTS.md) 按触发条件引用，不在此复制正文；本目录不是 skill registry，也不是把筹备
过程包装成工作流能力的地方。

只有当一个项目适配缺口已经有明确责任、独立 consumer、允许效果、失败边界和相称实践证据，才在本目录增加
临时 adapter；形成后必须在 `skill-formation-map.md` 登记来源、依赖、写面、归档和潜在晋升关系。单次筹备中的
元协调动作优先保持为 AGENTS 规则或筹备记录，不形成 active skill。

本目录自身随筹备项目结算归档，不是仓库的通用 skill 目录。
